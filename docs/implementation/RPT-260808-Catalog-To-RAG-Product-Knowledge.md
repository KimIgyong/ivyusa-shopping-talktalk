## 3. 설계에서 의도적으로 선택한 것

**변형은 접고, 라인은 접지 않습니다.** 처음 규칙(정규화 제목 첫 5단어)은 829행을 접었지만 KISS "Pure Glow Vita Bright" **5개 제품(클렌저·토너·모이스처라이저·아이패치·세럼)을 한 문서로 병합**했습니다. 지금 규칙은 **대시로 변형을 명시한 제목만** 접습니다(`… Core Colors - Aphrodite`). 접히는 행은 829 → 444로 줄었지만, 늘어난 문서는 전부 **원래 별개인 제품**입니다.

`in`은 구분자로 쓰지 않습니다. "Press-On Nails **in** Amiable"에는 맞지만 "2 **in** 1 Curling Iron", "All **In** One Lamination Kit"도 함께 쪼갭니다(카탈로그에 4건).

**사람이 쓴 문서는 건드리지 않습니다.** curated 문서(평균 1,894자, 사용법 포함)는 본문을 보존하고 **링크와 판매상태만** 갱신합니다 — 카탈로그가 권위를 갖는 사실은 그 둘뿐입니다. 대표 선출도 curated 문서를 가진 멤버를 우선합니다. 그러지 않으면 같은 제품을 서술하는 문서가 둘이 되고, 더 나은 쪽이 밀립니다.

**가격과 SKU는 본문에 없습니다.** 벡터 색인에 고정된 가격은 조용히 낡고, 틀린 가격은 오타가 아니라 분쟁입니다(PLN-260804 D4). SKU는 공백·중복이 있어 식별자가 되지 못합니다.

**단종은 삭제가 아니라 비활성입니다.** 이력·통계·되돌리기가 살아 있어야 합니다.

**충돌 스캔에서 상품 그룹을 제외했습니다.** 변형끼리 유사도가 후보 임계(0.85)를 한참 넘는 ~1.0이라, 포함하면 스캔당 판정 40건 예산을 "같은 제품의 다른 색"에 전부 소모하고 정작 찾아야 할 사실 상충을 굶깁니다.

**자동이 아닙니다.** 임베딩은 레이트리밋이 있고, 카탈로그 갱신이 지식베이스를 조용히 다시 쓰면 아무도 그것을 보지 못합니다. 미리보기 → 사람 승인 → 실행입니다.

## 8. 남은 결함 · 다음 단계

**D3 — 동기화 실행이 nginx 60초에서 504** → **해결 완료 (PR #153, 2026-08-08 배포)**

원인은 세 겹이었습니다. ① 라우트가 동기라 작업이 끝날 때까지 **응답 헤더조차 나가지 않음** ② 그 대기가 nginx `proxy_read_timeout` 기본값 60초를 초과(실측 111초) ③ 컨테이너·호스트 nginx 어느 쪽에도 타임아웃이 명시돼 있지 않음. 504를 낸 것은 컨테이너 nginx(1.31.2)이며, 에러 로그의 `upstream timed out … while reading response header`가 정확히 요청 +60초에 찍혔고 API 완료 로그는 +111초였습니다. **작업이 아니라 응답만 끊긴 것**이라 데이터는 매번 온전했습니다.

조치(A안): `POST`는 **202 + job**을 즉시 반환하고, `GET …/status`가 단계·건수를 보고합니다. 콘솔은 2초 간격으로 폴링해 **문서 작성 / 색인 2단 진행률**을 그립니다. 테넌트당 1건만 실행(중복은 409), 창을 닫아도 작업은 계속됩니다.

상태는 **메모리**에 둡니다 — 완료 기록은 이미 감사로그(`knowledge.catalog_synced`)에 건수와 함께 남고, 메모리는 재시작 후 가치가 없는 *실행 중 뷰*만 담기 때문입니다. 재시작으로 유실되면 재실행하면 되며 변환은 멱등입니다.

실측: 시작 응답 **0.068초 / HTTP 202**(이전 60초 → 504), 중복 실행 **409**, 진행률 `running writing 1827/1828` → `succeeded done write 1828/1828 embed 3/3 실패 0`.

**P2(유형별 사용법 문서)** — 이제 실데이터가 있으므로 유형 매핑을 확정할 수 있습니다. 상위 브랜드는 Red By Kiss 662 · Mad Shade 154 · Ruby Kisses 136 · Kiss New York 135 · I-ENVY 125이고, 사용법이 의미 있는 유형은 압온네일·속눈썹·헤어컬러·스킨케어 등 10~12종으로 상품의 68.2%를 덮습니다.

**P3(자동 전파)** — 현재는 카탈로그가 갱신돼도 지식은 수동 재실행이 필요합니다. 재실행은 멱등이므로 위험은 낮습니다.
