## 결정 제안

| # | 결정 | 제안 | 이유 |
|---|---|---|---|
| D1 | 어떤 대화를 목록에 넣나 | **필터 3종**: `상담 필요`(waiting+agent) · **`전체`(진행중 포함, 기본)** · `종료` | 요구는 "최신 대화가 보여야" — 기본을 전체로. 대기열만 보고 싶은 상담사를 위해 필터 유지 |
| D2 | 정렬 | **마지막 활동(마지막 메시지) 최신순**, 없으면 개설 시각 | "가장 최근 대화창"이 위에 오게 하는 핵심. 현재는 생성 id 순 |
| D3 | 이름 표기 | `고객명` → 없으면 `이메일` → 없으면 `Session xxxxxx`. 이름/이메일이 있을 땐 **세션 라벨을 보조 줄**로 병기 | 요구 2 그대로. 상담사는 누구인지 즉시 식별해야 함 |
| D4 | 스레드 시각 | 각 메시지 말풍선 옆 **HH:mm**, 날짜 바뀌면 **날짜 구분선** | 요구 3 |
| D5 | 페이지 크기 | 20 → **50**, 그리고 총 건수 표기 | 진행중 포함 시 20건은 금방 넘침. 페이징 UI는 이번 범위 밖(더보기 버튼은 후속) |

## Stage 1 — API (`GET /agent/sessions`)

대상: `apps/api/src/domain/agent/{agent.service.ts, agent-console.controller.ts, dto/request/agent.request.ts, agent.mapper.ts}`

1. `status` 쿼리 추가: `queue`(waiting+agent) | `all`(기본: waiting+agent+ai_active) | `ended`.
2. **마지막 활동 정렬**: 대상 대화의 마지막 메시지 id를 이미 배치 조회(`lastMessagesByConversation`)하므로,
   목록을 그 값 기준으로 정렬한다. 페이지 경계를 넘는 정렬 정확도를 위해
   `MAX(m.id)` 서브쿼리 조인으로 정렬을 **DB에서** 수행(인덱스 `idx_msg_conv` 사용).
3. 응답에 `customerEmail`(복호화 값) 추가 — `namesByIds`를 `contactsByIds`(id→{name,email})로 확장.
   추가 쿼리 없음(같은 행에서 필드 하나 더 select).
4. 기본 page size 50.

## Stage 2 — 콘솔 UI

대상: `apps/web/src/domain/live-chat/{LiveChatPage.tsx, live-chat.hooks.ts, live-chat.service.ts}`, `i18n/{en,es,ko}/livechat.json`

1. 목록 상단 **필터 칩**(상담 필요 / 전체 / 종료), 기본 `전체`. 선택값은 조회 키에 포함(5초 폴링 유지).
2. 행 렌더: 1줄 = **고객명(또는 이메일)** + 상태 배지, 2줄 = `Session 94` 보조 라벨,
   3줄 = 마지막 메시지 미리보기, 4줄 = 개설·마지막 시각(현행).
3. 스레드: 말풍선 하단에 시각(HH:mm), 날짜 경계에 구분선.

## 사이드 임팩트

| 영역 | 검토 | 판단 |
|---|---|---|
| 목록 건수 증가 | ai_active 포함 시 스테이징만 해도 다수 | 정렬·필터·size 50으로 흡수, 페이징은 후속 |
| 정렬 변경 | 대기열 우선순위가 "오래된 대기 먼저"에서 "최근 활동 먼저"로 바뀜 | 요구사항이 최신 우선. 필터 `상담 필요`로 대기열 뷰는 유지 |
| 이메일 노출 | 목록에 이메일 표기(이름 없을 때) | 콘솔은 이미 고객 패널에서 노출 — 동일 수준, 감사 로그 대상 아님 |
| 성능 | 정렬용 서브쿼리 조인 1회 추가 | `idx_msg_conv` + 기존 복합 인덱스로 흡수, 실측 4~20ms 수준 유지 예상 |
| 5초 폴링 | 필터별 캐시 키 분리 | React Query 키에 status 포함 |

## 검증 계획 (TCR)

- 단위: status 필터 3종 분기, 마지막 활동 정렬, 연락처 매핑(name/email/없음).
- 통합(스테이징): 진행중 대화 94가 **맨 위**에 뜨는지, 고객명·세션 라벨 병기, 이름 없는 고객은 이메일 표기,
  스레드 시각·날짜 구분선, 필터 전환, 검색과 필터 동시 적용.
