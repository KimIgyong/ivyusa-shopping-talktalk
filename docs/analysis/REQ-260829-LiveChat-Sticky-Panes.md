# REQ-260829 라이브챗 — 필터/검색·대화방 헤더 상단 고정 (스크롤 분리)

- 작성일: 2026-08-29
- 요청 유형: [요구사항] — /live-chat 콘텐츠 영역 스크롤 구조 개선

## 0. 요구사항 원문

1. 첫 번째 **세션 목록**에서 필터 영역과 검색바 영역을 상단 고정 — 목록이 길어져 스크롤해도 필터/검색바는 계속 노출.
2. 가운데 **대화방 내용 보기** 영역에서도 상단 상태·기능선택 영역은 고정하고 **대화 내용만 스크롤**.

## 1. AS-IS — 스크롤이 새는 지점 2곳

| # | 영역 | 현재 구조 | 증상 |
|---|---|---|---|
| A1 | 세션 목록 칼럼 | `col-span-3 overflow-y-auto` — **칼럼 전체가 하나의 스크롤 컨테이너**. 제목줄·상태 탭·그룹/채널/에이전트 필터·검색박스·목록이 모두 그 안에 평면 배치 | 목록을 내리면 필터·검색바가 함께 밀려 올라가 사라짐. 필터를 바꾸려면 매번 맨 위로 되스크롤 |
| A2 | 페이지 전체 | 그리드 높이가 고정 매직값 `h-[calc(100vh-220px)]`. 실제 상단 크롬(글로벌 헤더 64px + main 패딩 + PageHeader)과 어긋나면 그리드가 뷰포트를 넘어 **본문(body) 스크롤** 발생 | 중앙 대화 패널은 내부적으로 헤더 고정+메시지 스크롤 구조(flex-col + flex-1 overflow)가 이미 있으나, **본문이 스크롤되는 순간 세 칼럼의 상단이 통째로 화면 밖으로 밀림** — "상단 상태/기능 영역이 고정 안 됨"의 실체 |

- 중앙 패널 내부(헤더 2줄·IssuePanel·메시지·컴포저)는 flex 구조가 이미 올바름 — 문제는 A2의 바깥 스크롤.
- 우측 컨텍스트 칼럼(`overflow-y-auto`)·그룹 룸도 A2의 영향을 동일하게 받음.

## 2. TO-BE

### R1. 세션 목록 — 필터/검색 상단 고정
- 제목줄(세션 수·선택모드) + 상태 탭(전체/상담필요/종료) + 2번째 필터줄(그룹/채널/에이전트) + 검색박스를
  **고정 블록**으로, 그 아래 목록(그룹 목록 포함)만 스크롤.
- 스크롤 중에도 필터 변경·검색 입력 즉시 가능. 하단 그룹핑 액션바(sticky bottom)는 현행 유지.

### R2. 페이지 뷰포트 잠금 — "대화 내용만 스크롤"
- 라이브챗 페이지를 뷰포트 높이에 정합시켜 **본문 스크롤 자체를 제거**: 스크롤은 ① 세션 목록 ② 대화 메시지
  ③ 우측 컨텍스트 칼럼, 세 내부 영역에서만 발생.
- 결과: 중앙 상단(세션명/상태/자동응답/담당 배지 + 지정·이슈·싱크·수락·종료 버튼줄)과 IssuePanel·컴포저는
  항상 화면에 남고 대화 내용만 스크롤 — 요구 그대로.

## 3. 사용자 플로우
1. 상담원이 세션 50개 목록을 끝까지 내려도 상단에서 즉시 "상담필요" 탭 전환·고객명 검색.
2. 긴 대화를 과거로 스크롤하는 중에도 [수락]/[종료]/[동기화] 버튼과 상태 배지가 그대로 보임 — 스크롤 복귀 없이 조치.
