## 4. 알려진 한계

- **오리진 허용목록은 위조를 막지 못한다.** `parent_origin`은 클라이언트가 보내는 값이다.
  브라우저에서의 무단 임베드·오설치를 막을 뿐이며, 신원 증명은 서명이 담당한다(PLN §2.3).
- `session/ensure`는 `@SkipThrottle`이다. 오리진·IP 단위 상한은 **이 단계에 포함되지 않았다** —
  차단 모드 전환 시점에 함께 검토한다.
- 로더 테스트는 문자열 계약 검사다. 실제 브라우저 동작은 S-1·S-5 스모크가 확인한다.
