## 1. 무엇을 했나

좌측 상단 로고가 아무 동작도 없는 장식이었다. 대부분의 콘솔에서 로고는 어딘가로 가므로,
눌러보고 아무 일도 없으면 고장으로 읽힌다. 이제 `/menu`(전체 메뉴)로 간다.

메뉴 16개(마이페이지 포함)를 **아이콘 + 이름 + 한 줄 설명** 카드로 보여준다. 사이드바는 이름만
주는데, 이름만으로는 "작업로그"와 "대화 이력"이 어떻게 다른지 알 수 없고 접힘 모드에선 아이콘만 남는다.

## 2. 변경 파일

| 파일 | 변경 |
|---|---|
| `apps/web/src/domain/menu/MenuPage.tsx` **(신규)** | `nav-config` 기반 카드 그리드(1/2/3/4열 반응형) + 마이페이지 카드 |
| `apps/web/src/router/AppRouter.tsx` | `/menu`, 관리자 `/admin/menu` |
| `apps/web/src/layouts/Sidebar.tsx` | 로고 블록 → `NavLink`(접힘 상태 포함, `aria-label`/`title`) |
| `apps/web/src/i18n/locales/{en,es,ko}/menu.json` **(신규)** · `nav.json` | 제목·부제 + 항목별 설명, `allMenus` 라벨 |

## 3. 설계 결정

| 결정 | 이유 |
|---|---|
| 카드 목록을 **`nav-config`에서 파생** | 따로 선언하면 메뉴가 추가될 때 이 화면만 조용히 낡는다 |
| 사이드바와 **동일한 권한 필터**(`makeCan`) | 눌러서 403을 만나는 카드가 없어야 한다 |
| 마이페이지 카드 포함 | 사이드바 하단에 네비게이션과 떨어져 있어 존재를 놓치기 쉽다 |
| 설명은 `defaultValue: ''` 폴백 | 키가 없으면 원시 키를 노출하는 대신 이름만 있는 카드로 degrade |
| 로그아웃은 카드에 없음 | 화면이 아니라 동작이다 |
