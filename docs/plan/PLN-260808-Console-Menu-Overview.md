# PLN-260808-Console-Menu-Overview

좌측 상단 로고 클릭 → **전체 메뉴 카드뷰** 화면.

- 작성일: 2026-08-08
- 요청: "shoptalk - 좌측상단 로고 클릭하면 전체 메뉴를 카드뷰 메뉴로 보여주는 페이지를 작성하라"

---

## 1. AS-IS

- 사이드바 로고(스파클 아이콘 + 테넌트명)는 **아무 동작도 없는 장식**이다. 대부분의 콘솔에서 로고는 홈으로 가는 링크라, 눌러본 사용자에게는 고장처럼 보인다.
- 메뉴 전체를 한눈에 보는 화면이 없다. 사이드바는 접히면 아이콘만 남고(64px), 항목이 16개라 처음 쓰는 사람은 무엇이 있는지 알기 어렵다.
- 항목 이름만 있고 **설명이 없다** — "작업로그"와 "대화 이력"의 차이를 이름만으로 알 수 없다.

## 2. TO-BE

| ID | 요구사항 |
|---|---|
| FR-M1 | 사이드바 로고 클릭 → `/menu` 이동 (접힌 상태에서도 동작) |
| FR-M2 | 현재 사용자가 **접근 가능한 메뉴만** 카드로 표시(사이드바와 동일한 권한 게이팅) |
| FR-M3 | 카드마다 아이콘 · 메뉴명 · **한 줄 설명** |
| FR-M4 | 카드 클릭 → 해당 화면 이동 |
| FR-M5 | 시스템 관리자는 관리자 메뉴 카드를 본다 |
| FR-M6 | 마이페이지도 카드에 포함(사이드바 하단에만 있어 존재를 놓치기 쉽다) |

## 3. 와이어프레임 (신규 `/menu`)

```
┌ 전체 메뉴 ─────────────────────────────────────────────────────────────┐
│ ivyusa 콘솔에서 사용할 수 있는 모든 화면입니다.                        │
│                                                                        │
│ ┌───────────────────┐ ┌───────────────────┐ ┌───────────────────┐     │
│ │ ▣  대시보드        │ │ ▣  실시간 상담     │ │ ▣  대화 이력       │     │
│ │ 상담 현황과 지표를 │ │ 진행 중인 상담에   │ │ 지난 대화를 검색   │     │
│ │ 한눈에 봅니다      │ │ 응대합니다         │ │ 하고 확인합니다    │     │
│ └───────────────────┘ └───────────────────┘ └───────────────────┘     │
│ ┌───────────────────┐ ┌───────────────────┐ ┌───────────────────┐     │
│ │ ▣  작업로그        │ │ ▣  통계           │ │ ▣  AI 설정        │     │
│ │ …                 │ │ …                 │ │ …                 │     │
│ └───────────────────┘ └───────────────────┘ └───────────────────┘     │
│                              (2 / 3 / 4열 반응형)                      │
└────────────────────────────────────────────────────────────────────────┘
```

- 카드 = 아이콘(원형 배경) + 메뉴명(굵게) + 설명 한 줄, 전체가 링크.
- 권한이 없는 메뉴는 **아예 그리지 않는다**(사이드바와 같은 규칙) — 눌러서 403을 만나는 카드는 없다.

## 4. 구현

| 파일 | 변경 |
|---|---|
| `apps/web/src/domain/menu/MenuPage.tsx` **(신규)** | `TENANT_NAV`/`ADMIN_NAV`를 그대로 읽어 카드 렌더 + 마이페이지 카드 |
| `apps/web/src/router/AppRouter.tsx` | `/menu` 라우트(AppLayout 하위, 관리자 `/admin/menu`도 동일 페이지) |
| `apps/web/src/layouts/Sidebar.tsx` | 로고 블록을 `/menu` 링크로 (접힘 상태 포함, `aria-label`) |
| `apps/web/src/i18n/locales/{en,es,ko}/menu.json` **(신규)** | 제목·부제 + 항목별 한 줄 설명(키는 nav의 `labelKey` 재사용) |

**메뉴 목록은 `nav-config`를 단일 출처로 쓴다.** 카드 목록을 따로 선언하면 사이드바에 항목이 추가될 때 이 화면만 조용히 낡는다.

## 5. 사이드 임팩트

| 대상 | 영향 | 판단 |
|---|---|---|
| 백엔드 | 없음 | API·스키마 변경 없음 |
| 사이드바 동작 | 로고가 링크가 됨 | 기존 네비게이션 항목은 그대로 |
| 권한 | 신규 capability 없음 | 사이드바와 동일한 `makeCan` 게이팅 재사용 |

## 6. 리스크

| 리스크 | 대응 |
|---|---|
| 사이드바에 메뉴가 추가돼도 카드가 안 늘어남 | `nav-config` 단일 출처로 읽어 원천 차단 |
| 설명 i18n 키 누락 시 빈 카드 | 설명은 `t(key, '')` 폴백 — 이름만 있는 카드로 degrade |
