## 5. 미커버 (인지된 공백)

- **아메바톡 허브 미디어 payload**: 실제 수신 payload를 못 봐서 `content_type` + URL 형태로
  추론했다. 실채널 수신 1건으로 확인 필요.
- **바이버 file 발신의 `size` 필드**: 플랫폼이 실제 크기를 요구할 수 있음(현재 0 전송).
- **악성코드 스캐닝**: 설계상 범위 밖(REQ §5).
- **e2e HTTP 테스트(supertest)**: 리포지토리 전반의 기존 공백과 동일.
