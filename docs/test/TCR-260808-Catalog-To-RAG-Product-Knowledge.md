## 4. 잔여 과제

**D3(504)**: 1,689건 생성 + 27배치 임베딩에 약 4분이 걸리는데 nginx `proxy_read_timeout`이 60초입니다. 서버는 정상 완주했고 데이터도 완전하지만, **콘솔 조작자에게는 오류로 보이고 재클릭을 유발**합니다. PLN 와이어프레임의 진행률 표시도 동기 호출로는 구현할 수 없습니다.

선택지: ① 비동기 작업 + 상태 폴링(설계 의도에 부합, 작업량 큼) ② 해당 라우트만 프록시 타임아웃 상향(즉효, 조작자는 4분 대기) — **①을 권장**하되 별도 승인 사항입니다.
