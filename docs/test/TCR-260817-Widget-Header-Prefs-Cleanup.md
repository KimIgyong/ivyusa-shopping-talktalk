### 3.1 확인 과정에서의 오독 1건
토글이 저해상도 스크린샷에서 파랗게 보여 **API와 어긋난 줄 알았으나**, 확대해 보니
노브가 왼쪽(OFF)으로 API(`optOut:false`)와 일치했다. 결함이 아니라 판독 실수였고,
확대 후 정정했다. 기록해 두는 이유: 스크린샷 한 장으로 상태를 단정하면 안 된다.
