## 요구 3 — 위젯의 이메일/SMS/앱푸시 설정 제거

### AS-IS
`PreferencesPanel.tsx:330-380` — **카테고리 × 채널 매트릭스 토글**.
- 채널 4종: `in_app`(항상 켬·비활성) · `email` · `sms` · `web_push`
- 카테고리 5종: payment / shipping / event / review / chat

### 제거해도 안전한 근거 (조사 결과)

| 축 | 사실 | 의미 |
|---|---|---|
| 마케팅 발송 | pref 행이 없으면 **external 채널 default-deny** (`notification.service.spec.ts:60`) | UI를 없애도 **마케팅 스팸이 늘지 않는다** |
| CCPA 옵트아웃 | `usePrivacy`의 별도 컨트롤(`optOut`)이 담당 — 매트릭스와 무관 | **컴플라이언스 컨트롤이 아니다** |
| 모바일 앱 / PWA | `setPref(token, **'push'**, ...)`만 사용 — 자기 기기의 푸시만 관리 | 위젯에서 빼도 **앱 푸시 설정은 그대로 살아 있다** |
| 전체 매트릭스 UI | **위젯에만 존재** | 다른 앱 영향 없음 |

### 제거 시 실제로 잃는 것 (하나뿐)
**거래성(transactional) 이메일·SMS를 고객이 스스로 끌 수단이 사라진다.**
payment/shipping/chat은 pref 행이 없으면 default-**allow**이므로, 매트릭스를 없애면
"주문 알림 문자 그만 받기"를 고객이 위젯에서 할 수 없다.
