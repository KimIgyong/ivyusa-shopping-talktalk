## 1. 요금 체계 (2026-08-02 기준)

| 모델 | 단가 (100만 토큰당) | 무료 쿼터 | Tier 1 한도(결제수단 등록만) |
|---|---|---|---|
| **voyage-4** (현재 사용) | **$0.06** | **누적 200M 토큰 무료** | 2,000 RPM / 8M TPM |
| voyage-4-lite | $0.02 | 200M 무료 | 2,000 RPM / 16M TPM |
| voyage-4-large | $0.12 | 200M 무료 | 2,000 RPM / 3M TPM |
| rerank-2.5 (미사용, 후보) | $0.05 | 200M 무료 | — |
| voyage-4-nano | **무료(오픈웨이트, Apache 2.0)** — 자가호스팅 | — | 자체 인프라 한도 |

- 유료 티어 자동 승급: 누적 결제 $100↑ = 한도 2배, $1,000↑ = 3배. 승급은 영구.
- Batch API는 33% 할인(무료 쿼터 미적용).
- ⚠️ **레이트리밋 해결에 비용이 들지 않음**: 결제수단 등록만 하면(청구 0원) Tier 1의
  2,000 RPM이 열림 — 현재 무료 티어 429 문제의 즉시 해법.

## 3. 비용 시뮬레이션 (voyage-4, 월 기준)

| 시나리오 | 월 채팅량 | 질의 토큰 | 재색인/증분 | 월 토큰 합계 | **월 비용(무료 소진 후)** | 200M 무료로 버티는 기간 |
|---|---|---|---|---|---|---|
| S1 스테이징·데모 | 1천 건 | 4만 | 3만 | ~0.1M | **$0.006** | 160년+ |
| S2 운영 초기 (일 1천 건) | 3만 건 | 120만 | 10만 | ~1.3M | **$0.08** | ~12년 |
| S3 성장기 (일 1만 건) | 30만 건 | 1,200만 | 100만 | ~13M | **$0.78** | ~15개월 |
| S4 대규모 (일 3.3만 건 + 상품지식 1만 건 월 1회 전량 재색인) | 100만 건 | 4,000만 | 500만 | ~45M | **$2.70** | ~4개월 |
| S5 극단 (S4×2 + 리랭커 도입 전) | 200만 건 | 8,000만 | 1,000만 | ~90M | **$5.40** | ~2개월 |

**결론: 임베딩 자체는 어떤 현실적 시나리오에서도 월 수천 원 이하.** 사실상 "무료 200M 토큰"이
S3 기준 1년 이상을 커버하며, 소진 후에도 연 $10 미만~$65 수준이다.

### 유일하게 비용이 커지는 경로 — 리랭커(rerank-2.5)
리랭커는 질의당 **후보 문서 전체 토큰**을 과금(질의+상위 8건×~300토큰 ≈ 2,400토큰/질의).
- S3(월 30만 건): 7.2억 토큰/월 → **월 $36**
- S4(월 100만 건): 24억 토큰/월 → **월 $120**
→ 리랭커 도입 시에는 rerank-2.5-lite($0.02/M, 위 비용의 40%) 또는 상위 후보 축소(8→4건)로
설계 단계에서 비용을 통제할 것. *현재 파이프라인은 리랭커 미사용이므로 해당 없음.*

## 4. 비용 과다 시 대안 (조사 결과)

전환 비용이 낮도록 설계되어 있음: `AiAdapter.embed()` 인터페이스 + `embedding_model` 컬럼 +
`kb:reindex --force`(전량 재색인 수 분, 재색인 자체 비용 ~3만 토큰). 모델 교체 = 어댑터(또는
`VOYAGE_MODEL` env) 변경 + 재색인 1회.

### 대안 A — 동일 생태계 다운시프트 (전환 비용 최소)
- **voyage-4-lite**: $0.02/M (voyage-4의 1/3), TPM 2배. env `VOYAGE_MODEL=voyage-4-lite` +
  재색인만으로 전환. 품질 소폭 하락(리테일 CS 질의엔 대체로 충분). **1순위 다운시프트.**
- Batch API(33% 할인): 대량 재색인을 배치로 — 현 규모에선 실익 미미.

### 대안 B — 자가호스팅 (API 비용 0, 데이터 외부 반출 0)
- **voyage-4-nano**: Voyage가 공개한 **오픈웨이트(Apache 2.0, Hugging Face)** 모델 —
  같은 계열이라 품질 특성 예측 가능. 스테이징 서버에 컨테이너 1개
  (Hugging Face **TEI**(text-embeddings-inference) 이미지, CPU로 소규모 충분)로 서빙 →
  어댑터 endpoint만 교체. **비용 과다 시 최우선 대안.**
- 범용 오픈소스: **BGE-M3**(다국어·한국어 강함, 1024차원), multilingual-e5-large,
  한국어 특화 KURE 계열 — 모두 TEI로 동일하게 서빙 가능. 단, 모델별 품질 재검증 필요
  (스모크 하니스 + 30문항 평가 세트 재실행).
- 유의: 자가호스팅은 API 비용 대신 **서버 자원·운영 부담**을 지불 — 현 단일 서버에
  CPU 서빙 추가는 가능하나, 대량 트래픽이면 별도 노드 필요.

### 대안 C — 타 상용 API (참고, 채택 시 단가 재확인 필요)
| 제공자 | 모델 | 단가/M | 비고 |
|---|---|---|---|
| OpenAI | text-embedding-3-small | ~$0.02 | 다국어 무난, 1536차원(축소 가능) |
| OpenAI | text-embedding-3-large | ~$0.13 | 품질 상위 |
| Google | gemini-embedding | ~$0.15 | 다국어 강함, 무료 티어 존재 |
| Cohere | embed-v4 | ~$0.12 | 다국어·검색 특화 |
→ 단가 수준이 Voyage와 동급이거나 높아 **비용 절감 목적의 전환 실익은 없음**. 의미가 있는
경우는 조직 표준/계약(예: OpenAI 크레딧 보유) 정도.

### 대안 선택 가이드
| 트리거 | 권장 대안 |
|---|---|
| 월 비용 > $50 (사실상 리랭커/초대형 코퍼스) | A(lite) → 부족하면 B(voyage-4-nano 자가호스팅) |
| 데이터 주권/외부 API 금지 요건 | B (nano 또는 BGE-M3 자가호스팅) |
| Voyage 서비스 종료/정책 변경 | B가 안전망 (오픈웨이트 확보됨) |
| 레이트리밋만 문제 | 대안 불필요 — 결제수단 등록(Tier 1, 무과금)으로 해결 |

## 5. 권고 (실행 항목)

1. **지금**: Voyage 대시보드에 결제수단 등록 — 비용 0원으로 2,000 RPM 확보(429 해소).
   무료 200M 토큰이 먼저 소진되기 전까지는 청구가 발생하지 않음.
2. **모니터링**: Voyage 대시보드 usage 페이지를 월 1회 확인. 월 소모가 50M 토큰(≈$3)을
   넘기 시작하면 리랭커/코퍼스 설계를 점검.
3. **비용 알람 기준**: 월 $50 초과 전망 시 위 "대안 선택 가이드"에 따라 A→B 순으로 전환.
   전환 리허설(voyage-4-lite 재색인 + 평가 세트)은 반나절 작업.
4. 리랭커 도입 검토 시에는 반드시 본 문서 §3의 리랭커 비용 모델로 사전 시뮬레이션할 것.
