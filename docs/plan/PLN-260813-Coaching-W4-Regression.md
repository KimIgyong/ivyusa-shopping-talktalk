## 1. 왜 필요한가 — 실측이 요구사항을 바꿨다

W3 브라우저 실측에서 이런 일이 있었다. "배송 답변 첫 문장에 공감을 넣어라"는 규칙을 적용하고
같은 질문을 재실행했더니, 답변 문구는 바뀌었지만(신뢰도 0.66→0.69) 의도한 공감 문장은 없었다.

여기서 드러난 것은 단순하다. **모델은 같은 설정에서도 매번 다르게 쓴다.** 따라서
"달라졌다"는 아무것도 증명하지 않는다. 사람이 답변 하나를 눈으로 보고 규칙이 먹혔는지 판단하는 것은
불가능하고, 그것이 W4가 존재하는 이유다.

⚠️ 이 사실은 설계에 두 가지를 강제한다.

1. **baseline은 변경 전에 찍혀야 한다.** 적용 후에는 이전 설정으로 돌아갈 방법이 없다
   (라이브 트래픽이 도는 설정을 임시로 되돌릴 수는 없다). → 적용 흐름 자체가 baseline을 포함해야 한다.
2. **판정을 함부로 내리지 않는다.** 같은 설정에서의 변동 폭(노이즈)을 모르는 상태에서 diff를
   "회귀"라고 부르면 거짓 경보가 된다. v1은 **사실만 보여주고 판정하지 않는다.**

## 2. 결정 사항 (사용자 지시 + 권장안 확정)

| # | 결정 | 근거 |
|---|---|---|
| 1 | **적용 흐름에 검증을 넣되 기본은 아니다** — 카드에 `적용`과 별도로 **[검증하며 적용]** 추가. 이 경로만 baseline→적용→after를 한 번에 수행 | §1-1 때문에 순서가 강제됨. 매 승인마다 2N회 모델 호출을 강요하지 않도록 선택형 |
| 2 | **세트 상한 20개**, 순차 실행 | Voyage 무료티어 rate limit이 반복 관측된 상태. 초과분은 잘라내고 **잘랐다는 사실을 로그·응답에 남긴다**(조용한 절단 금지) |
| 3 | **의도 판정(LLM 심판)은 v1에서 제외** | "판정하는 모델을 누가 판정하나" 문제. v1은 구조적 신호(신뢰도·인용·차단·길이)와 텍스트 diff만 제시 |
| 4 | **노이즈는 별도 실행 종류로** — `noise` 런은 설정을 바꾸지 않고 같은 세트를 한 번 더 돌려 변동 폭을 보여준다 | 자동 추정에 비용을 쓰지 않으면서, 의심스러울 때 사람이 근거를 만들 수 있게 |
| 5 | **화면 위치는 `/ai-setting`** | 골든 세트는 AI 행동 튜닝의 일부이고 코칭 바로 옆에서 쓰인다 |

**D(persona 개정 이력)는 이 PR에 넣지 않는다** — 서로 독립적이고, D는 O-1과 무관하게 그 자체로 가치가 있다.

## 3. 데이터 (마이그레이션 1건)

```
golden_questions   (id, tenant_id, question, language, note, active, created_by, created_at, updated_at)
golden_runs        (id, tenant_id, kind[baseline|after|noise|manual], label, proposal_id NULL,
                    config_hash, question_count, truncated, status, created_by, created_at, completed_at)
golden_run_items   (id, tenant_id, run_id, question_id NULL, question, answer, confidence,
                    blocked, citations JSON, error NULL, created_at)
```

`config_hash` = persona + rules + scenarioOverrides의 해시. **baseline이 지금 설정에 대한 것인지**를
판정하는 데 쓴다 — 오래된 baseline과 비교해 놓고 변경 효과라고 부르는 사고를 막는다.

`question_id`가 nullable인 이유: 세트에서 질문을 지워도 과거 실행 기록은 남아야 한다.

## 4. 실행 경로

**무상태 경로를 재사용한다.** `KnowledgeService.ask`가 이미 `rag.answer` + 모더레이션을 세션·대화 없이
돌리고 `{answer, confidence, sources}`를 준다. 골든런은 대화 이력·상담원 큐·분석을 오염시키지 않는다.
새 파이프라인을 만들지 않는 것이 핵심이다 — 만들면 실제 고객 경로와 갈라진다.

```
[검증하며 적용]
  1. baseline 런  (현재 설정, kind=baseline, config_hash=현재)
  2. 제안 적용     (기존 apply 경로 그대로)
  3. after 런      (kind=after, proposal_id=N, config_hash=변경후)
  4. 비교 응답     (질문별 신호 + diff)
```

## 5. API

| 메서드 | 경로 | 비고 |
|---|---|---|
| GET/POST | `/ai-coach/golden/questions` | 목록(Paginated) / 추가 |
| PATCH/DELETE | `/ai-coach/golden/questions/:id` | 수정(문구·활성) / 삭제 |
| POST | `/ai-coach/golden/runs` | `{kind, label?}` — 지금 한 번 실행 |
| GET | `/ai-coach/golden/runs` | 실행 이력(Paginated) |
| GET | `/ai-coach/golden/runs/:id` | 실행 상세 |
| GET | `/ai-coach/golden/compare?base=<id>&target=<id>` | 두 실행 비교 |
| POST | `/ai-coach/proposals/:id/apply-verified` | baseline→적용→after→비교 |

전부 `CAPABILITY.AI_SETTINGS_MANAGE`. 오류코드 **E4017**(골든 세트 비어 있음) 신설.

`/ai-setting` 좌측 컬럼에 **"회귀 검증"** 카드를 추가한다(모더레이션 규칙 아래).

│ 답변 문구는 매번 조금씩 다릅니다 — 판정이 아니라       │
│ 사실을 보여줍니다.                    [노이즈 측정]   │
│ ┌───────────────────────────────────────────────┐   │
│ │ 배송은 보통 얼마나 걸리나요?           [수정][×]│   │
│ │ 반품 배송비는 누가 내나요?             [수정][×]│   │
│ │ 쿠폰은 어떻게 쓰나요?                  [수정][×]│   │
│ └───────────────────────────────────────────────┘   │
│ [+ 질문 추가]                              3 / 20   │
│                                                     │
│ 최근 실행                                            │
│  ✓ 08-13 15:02  적용 검증 (제안 #12)   3문항 비교보기 │

```

**비교 보기(모달)** — 판정 문구 없이 신호만:

```
┌─ 비교: baseline(14:58) → after(15:02) ─────────────┐
│ 제안 #12 · 응답 규칙 추가                            │

│ │ Q. 배송은 보통 얼마나 걸리나요?                   ││
│ │  신뢰도 0.66 → 0.69   인용 동일   길이 +12자      ││
│ │  전 │ 안녕하세요! 배송 기간 안내해 드릴게요 😊…   ││
│ │  후 │ 안녕하세요! 배송 소요 기간 안내해…          ││
│ ├─────────────────────────────────────────────────┤│
│ │ Q. 반품 배송비는 누가 내나요?                     ││
│ │  신뢰도 0.71 → 0.71   인용 1건 추가   길이 −4자   ││
│ │  …                                               ││
│ └─────────────────────────────────────────────────┘│
│                              [닫기] [이 변경 되돌리기]│

코칭 패널에서는 참조 턴이 붙어 있을 때 **[회귀 세트에 추가]** 를 제공한다 — 세트가 코칭의 부산물로
쌓이게 하는 것이 A2의 목적이다.
