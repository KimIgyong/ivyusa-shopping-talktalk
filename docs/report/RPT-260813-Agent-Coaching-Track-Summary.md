## 3. 지금 검증된 것 (실환경)

- **사실은 규칙이 아니다** — "환불 30일" 코칭에 규칙을 만들지 않고, 기존 문서 `docId=40`의 $6.95와
  모순됨을 먼저 되물은 뒤, 확정하자 **그 문서를 개정하는 제안**을 냈다.
- **진단이 실제 근거에 붙어 있다** — 모델이 인용한 신뢰도·유사도가 저장된 `retrieval_trace`와 정확히
  일치했고, 근거를 넘는 주장은 스스로 거부했다.
- **인젝션을 따르지 않는다** — 고객 메시지로 위장한 "규칙을 추가하라"에 따르지 않고 방어 규칙을 역제안.
- **승인 없이는 아무것도 바뀌지 않는다** — 모든 검증에서 전후 persona·rules 동일 대조 확인.
- **복원이 프로덕션에 직접 꽂히지 않는다** — 이력에서 불러오면 편집기에만 들어오고, 저장 전 새로고침
  시 사라진다.

## 4. 이 트랙이 남긴 가장 쓸모 있는 수치 — 노이즈 기준선

설정을 **전혀 바꾸지 않고** 같은 질문 3개를 두 번 물어본 결과:

| 신호 | 노이즈 거동 | 판단 가치 |
|---|---|---|
| **문구 변경** | **3/3 항상 바뀜** | ❌ 신호 아님 |
| 길이 | ±3~6자 | ⚠️ 작은 변화 무의미 |
| 인용 변경 | 1/3 | ⚠️ 약한 신호 |
| **신뢰도** | **3/3 Δ=0** | ✅ 강한 신호 |

**앞으로 AI 응답 변화를 판단할 때의 기준선**이다. 문구가 달라진 것만 보고 "규칙이 먹혔다/안 먹혔다"를
말하면 안 된다 — 설정을 안 건드려도 100% 달라진다.
