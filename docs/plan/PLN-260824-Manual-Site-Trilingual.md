## 1. 카드뷰 와이어프레임 (필수)

```
┌────────────────────────────────────────────────────────────┐
│  SHOPTALK 사용자설명서                    [한국어|EN|VI]   │  ← 언어 토글(즉시 전환,
│  샵톡 매뉴얼                                               │     localStorage 기억)
│  개설부터 운영까지 — 3권으로 안내합니다                    │
├────────────────────────────────────────────────────────────┤
│ ┌─────────────────┐ ┌─────────────────┐ ┌───────────────┐  │
│ │ ①               │ │ ②               │ │ ③             │  │
│ │ 간단 세팅       │ │ 지식 등록·AI    │ │ 통합 사용자   │  │
│ │ 매뉴얼          │ │ 설정 매뉴얼     │ │ 매뉴얼        │  │
│ │ 테넌트 개설→    │ │ 지식 파이프라인 │ │ 전 화면 참조  │  │
│ │ 첫 상담까지     │ │ ·검증·AI·라이브챗│ │ (v2.0)        │  │
│ │                 │ │                 │ │               │  │
│ │ [HTML 보기]     │ │ [HTML 보기]     │ │ [HTML 보기]   │  │
│ │ [MD 원문]       │ │ [MD 원문]       │ │ [MD 원문]     │  │
│ └─────────────────┘ └─────────────────┘ └───────────────┘  │
│  ⚠ EN·VI는 AI 번역 초안(원어민 검수 전) 고지 한 줄          │
└────────────────────────────────────────────────────────────┘
```
- 모바일: 카드 1열 세로 적층. 카드의 [HTML 보기]가 주 동작(강조), [MD 원문]은 보조 링크.
- 언어 토글은 **카드 링크 대상**(예: `quick-setup.en.html`)과 카드 문구를 함께 바꾼다.
- 디자인: 매뉴얼 아티팩트와 동일 아이덴티티(브랜드 블루 #2B7FFF, Gothic A1/IBM Plex Sans KR,
  라이트/다크 자동).

## 2. 산출물·파일 배치

| # | 경로 | 내용 |
|---|---|---|
| S1 | `apps/web/public/manual/index.html` | 카드뷰 인덱스 (3언어 문자열 내장 + 토글 JS) |
| S2 | `apps/web/public/manual/{quick-setup,knowledge-ai,user-manual}.{ko,en,vi}.md` | md 9개 (ko는 docs/guide 원본의 사본) |
| S3 | 동일 이름 `.html` 9개 | 아티팩트 디자인 템플릿으로 각 md 내용을 정적 HTML화 |
| S4 | `docker/staging/nginx.web.conf` | `.md → text/markdown; charset=utf-8` MIME 1건 추가 |
| S5 | `apps/api/src/global/constant/reserved-slug.constant.ts` | `'manual'` 예약어 추가 |
| S6 | `docs/guide/GUIDE-260824-*` 2종 + `사용자매뉴얼_*.ko.md` 상단 | "온라인판: /manual" 링크 1줄 추가 |

서빙 경로 검증: Vite가 `public/`을 dist로 그대로 복사 → 웹 nginx `try_files $uri $uri/`가
실존 파일을 SPA 폴백보다 먼저 매칭 → nginx location 추가 없이 `/manual/…` 동작.
`/manual`(슬래시 없음)은 `$uri/` + `index index.html`로 처리.

## 4. 부수 영향 분석

- **웹 콘솔 SPA**: 영향 없음(정적 파일이 우선 매칭될 뿐 라우터 변경 없음).
- **API**: 예약 슬러그 1건 추가 — 기존에 `manual` 슬러그 테넌트가 없음(신규 생성만 차단,
  기존 데이터 영향 없음). 이름에서 파생돼 `manual`이 되는 경우 기존 로직대로 `-shop` 접미.
- **PWA/위젯**: 영향 없음(별도 컨테이너·경로).
- **빌드 크기**: 정적 문서 19파일(예상 수백 KB) — dist 증가 미미, gzip 대상.
- **문서 이원화 리스크**: `docs/guide` ko 원본과 `public/manual` 사본의 불일치 가능 →
  각 원본 상단에 "개정 시 public/manual 사본·번역판 동반 갱신" 주석 명시(운영 규칙).
