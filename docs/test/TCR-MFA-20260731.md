## 4. 엣지 케이스 기록

- 활성화 직후 같은 time-step 코드는 step-up에서 재사용 불가(`last_used_step`) — 스모크에서 +1 스텝 코드 사용으로 우회 확인
- `MFA_ENFORCE_FROM` 파싱 불가 값은 **fail-open(비활성)+warn** — 잠금 사고 방지를 위한 의도적 설계(오타로 전 관리자 락아웃 방지)
- `pwdPending`+`mfaPending` 동시 상태: change-password가 `@AllowPendingMfa`를 겸해 데드락 없음(비밀번호 변경 → MFA 등록 순서)
