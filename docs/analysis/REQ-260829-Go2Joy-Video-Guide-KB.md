## 2. AS-IS (go2joy 지식베이스 현황, 스테이징 실조회)

- 총 83건 — `counsel` 22건 / `operation` **61건** / `product` 0건
- `operation` 61건 = 기존 운영매뉴얼 60건(`GTJ-*` ko / `-EN` / `-VI` 3판) + 보드 채택본 `BRD-1` 1건
- 카테고리는 **언어별 라벨**로 분리 운영: 객실 유형 관리/Room Type Management/Quản lý loại phòng(각 15),

  (`POST /knowledge/documents/import/bulk`, 업서트 축 = `(tenant, doc_group, external_key)` → 재업로드 멱등)

**갭**: 영상 가이드 51편은 지식으로 **0건** 등재. 텍스트 매뉴얼에는 없는 *정확한 클릭 경로·화면 라벨·
입력 필드·저장 후 결과*가 여기에만 있다.

## 5. 제약·판단 근거

- **AI 인제스트 경로를 쓰지 않는다.** 방금 추가한 md 인제스트로도 넣을 수는 있지만 ① LLM이 원문을
  다시 쓰면서 화면 라벨(`Chờ nhận phòng` 등)이 변형될 위험, ② 승인 결과가 **보드**에 게시되므로
  요구("지식베이스문서에 추가")와 목적지가 다르고, ③ 51편 × 2언어를 검수 승인해야 하며,
  ④ 병기 문서라 언어 분리가 불가능하다. 원문이 이미 아티클 단위로 규칙적이므로
  **결정적 변환기 + 일괄등록**(기존 go2joy 운영지식과 동일 경로)이 정확·멱등·무비용이다.
- **한국어판은 만들지 않는다.** 원문에 없는 언어를 지어내지 않는다. 필요하면 기존 EN/VI 번역판
  선례(PR #433/#434)처럼 별건으로 번역해 `GTJ-VID-*`(무접미) 키로 추가.
- **영상 길이(Duration)는 지식이 아니다** — 제외. 반대로 **Không đọc được/Not verifiable**은 유지:
  "영상이 성공 토스트까지 담지 않았다"는 사실을 지워버리면 KB가 확인되지 않은 결과를 단정하게 된다.
- 목차 표는 개별 문서와 중복이라 제외.
- 기존 텍스트 매뉴얼 문서와 주제가 겹친다. 제목 접두 `Video N —`과 본문 첫 줄 화면경로로 구분되며,
  둘은 경쟁이 아니라 보완(무엇을/어디를 누르는가)이다.
