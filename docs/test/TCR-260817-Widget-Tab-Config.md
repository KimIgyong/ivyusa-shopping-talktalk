### 3.1 구현 중 발견해 고친 결함
**`?reopen` 딥링크가 테넌트 설정보다 먼저 평가됐다.** 최초 구현은 마운트 시점에 `visibleTabs`를 읽었는데,
그때는 아직 시드 기본값(`notifications`+`chat`)이라 주문 탭을 보여주는 테넌트에서도 `?reopen=orders`가
알림 탭으로 착지했다. 1차 수정(레이아웃 변경 시 재평가)도 **첫 패스에서 의도를 소비**해 버려 보정이
일어나지 않았다. 최종적으로 `tabsResolved` 플래그를 두어 **실제 레이아웃이 도착한 뒤에만 의도를 소비**한다.
→ S-8이 이 경로의 회귀 가드다.
