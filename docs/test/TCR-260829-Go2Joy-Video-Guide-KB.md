## 1. 변환기 자체 검증 (`scripts/convert-go2joy-video-kb.mjs`)

스크립트가 실행 중 스스로 검사하고, 실패하면 **비정상 종료(exit 1)** 한다 — CSV만 보고 눈으로
넘기지 않게.

| # | 검사 | 기준 | 결과 |
|---|---|---|---|
| C1 | 아티클 수 | 정확히 51편 아니면 실패(원본 포맷 변경 감지) | 51 + 참고 1 = **52행** (언어별) |
| C2 | 제목 이중언어 분리 | `/ Video N — ` 리터럴 없으면 실패 | 51/51 성공 |
| C3 | 카테고리 매핑 | 구간표가 못 덮는 번호면 실패 | 11종 분포 = PLN 표와 일치 |
| C4 | **언어 분리 증명** | 버린 반쪽이 **같은 문서의 한 줄로** 살아남으면 실패 | VI/EN 각 **634개 반쪽 폐기, 0개 생존** |
| C5 | `<br>` 잔재 | 본문·제목에 0 | 0 |
| C6 | 제목 길이 | 255자 이하 | VI 최대 114 / EN 최대 128 |

**C4 설계 근거(중요)**: "이탤릭(`*…*`)이 남았나"로 검사하면 원본이 쓰는 **필수입력 표시**
(`Tên đăng nhập *`, `(*)`)를 전부 오탐한다. 또 문서 **전체 문자열 포함**으로 검사하면, 이 가이드가
*의도적으로* 영어 문장 안에 베트남어 화면 라벨을 인용하는 규칙(원문 §분석 방법)을 위반으로 몰아
버린다. 그래서 **같은 아티클 안에서 줄 단위 일치**만 위반으로 본다 — 아티클을 넘나들며 비교해도
안 되는데, 같은 화면을 다루는 두 영상은 화면경로 줄이 정당하게 동일하기 때문이다(Video 6·7).
