## 1. 무엇이 만들어졌나

1. **채택(promote)**: 게시된 보드 문서를 KB에 `BRD-{id}` 키로 업서트(source=board,
   2차 분류 우선 카테고리 매핑+리뷰어 오버라이드, 그룹별 ensure, 재임베딩). **재채택=
   동일 키 갱신 — 중복 0.** reject(보류)/reopen(게시 복귀, KB 행은 잔존) 전이 + 감사 3종.
2. **개정 감지**: 보드 원본과 KB 사본의 **내용 비교(제목+본문)** — 최초 구현(타임스탬프
   비교)은 로컬 스모크에서 같은 초 내 편집을 놓쳐 교체. 내용 비교는 리뷰어의 카테고리
   오버라이드를 영구 '미반영'으로 오탐하지도 않는다. 보드 상세에 뱃지+[재채택].
3. **시뮬레이션**: `rag.answer`에 선택적 후보 주입 — 즉석 임베딩·코사인으로 검색 순위에
   정직하게 병합, 컨텍스트에는 항상 포함, **Qdrant 미기록**(채택 전 문서가 실고객 답변에
   닿는 경로 0). 미전달 시 프로덕션 경로 무변경(기존 rag 스펙 전부 회귀 통과).
   응답=답변(모더레이션 게이트 유지)+confidence+**후보 인용 여부·유사도(미인용이어도)**.
4. **골든 A/B**: 활성 골든 질문(상한 10)을 후보 미포함/포함 2회씩 실행 → 문항별
   Δconfidence·후보 인용, 요약(인용 수·평균 Δ) — 절대 정확도가 아닌 **개선 수치**.
   골든 부재 시 E4017 안내.
5. **인제스트 재타깃(REQ C2 완성)**: AI 임포트 승인이 KB 직행 → **보드 게시**(published,
   `ai-import` 태그). "외부 자료는 1차 Board 저장" 요구가 파이프라인 전체에서 성립.
6. **콘솔**: 보드 편집 리뷰 바([시뮬레이션][KB 채택][보류], master/director — 서버
   매트릭스 동일 게이팅), 시뮬레이션 모달(골든 A/B 표+비용 고지+모달 내 채택), 보드
   상태 필터 칩, KB 목록 **출처 뱃지**(보드/직접/파일/YouTube/Drive/Notion/카탈로그),
   BRD 문서 상세 "보드 원본 열기"+분기 경고. 6개 언어.
