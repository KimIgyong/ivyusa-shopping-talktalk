# 채팅위젯 설정 가이드

콘솔에서 채팅위젯을 어디서 어떻게 바꾸는지 정리한 문서입니다.
2026-08-18 기준.

---

## 1. 어디로 가나

```
콘솔 로그인 → 좌측 메뉴 [설정]
```
설정 페이지에는 카드가 여러 장 세로로 쌓여 있습니다. 위젯 관련은 아래 세 장입니다.

| 찾는 것 | 카드 이름 |
|---|---|
| 탭 노출 / 탭 위치 | **위젯 탭 구성** |
| 브랜드 색 / 헤더 | **위젯 테마** |
| 로그인 방식 · 타임존 · 인사말 | **위젯 동작** |
| 알림을 어떤 경로로 보낼지 | **알림 채널** |

> 2026-08-18 이전에는 탭 설정이 **위젯 동작** 카드 안에 있었습니다. 찾기 어렵다는 지적이
> 반복되어 **위젯 탭 구성**이라는 별도 카드로 분리했습니다.

---

## 2. 위젯 탭 구성

```
┌─ 위젯 탭 구성 ──────────────────────┐
│ 노출 탭   ☑ 알림  ☑ 주문  ☑ 채팅   │
│           최소 한 개는 켜야 합니다.  │
│ 탭 위치   [ 상단 ▾ ]                │
│                        [ 저장 ]     │
└─────────────────────────────────────┘
```

- **노출 탭** — 켠 탭만 위젯에 나타납니다. 마지막 한 개는 해제할 수 없습니다(탭이 없으면
  위젯을 조작할 수 없습니다).
- **탭 위치** — `상단`은 제목 아래 텍스트 탭, `하단`은 위젯 맨 아래 아이콘+라벨 탭입니다.
- 기본값은 **알림 · 주문 · 채팅 3탭 / 상단**입니다.

### 주문 탭을 끄면 어떻게 되나
주문 관련 필터(**결제 · 배송 · 리뷰 · 문의**)가 사라지지 않고 **알림 탭으로 합쳐집니다.**
탭을 끈다고 기능이 없어지지는 않습니다.

| 알림 | 주문 | 칩 배치 |
|---|---|---|
| ON | ON | 알림 `전체·이벤트` / 주문 `결제·배송·리뷰·문의` |
| ON | OFF | 알림이 6개 전부 |
| OFF | ON | 주문이 6개 전부 |

## 3. 위젯 테마

```
┌─ 위젯 테마 ─────────────────────────┐
│ 브랜드 색  [ #2B7FFF ] ■            │
│ 헤더       [ 흰색 ▾ ]               │
│            ┌ 미리보기 ┐            │
│                        [ 저장 ]     │
└─────────────────────────────────────┘
```

- **브랜드 색 하나만** 정하면 됩니다. 밝고 어두운 단계는 자동 생성되고, 런처·유저 말풍선·
  전송 버튼·배송 스테퍼·링크가 그 색을 따릅니다.
- **글자색은 고를 수 없습니다.** 배경 밝기에 맞춰 흰색/짙은 회색이 자동 선택됩니다.
  밝은 색을 골라도 버튼 글씨가 보이지 않는 일이 생기지 않습니다.
- **헤더** — `흰색`은 디자인 기본, `브랜드 색`은 헤더를 브랜드 색으로 채웁니다.
- **상태 색상은 바뀌지 않습니다.** `확정`(초록) · `배송중`(주황) · 미읽음(빨강) · `리뷰`(보라)는
  의미를 지닌 색이라 테마 대상이 아닙니다.
- 설정하지 않으면 현재 기본 색(`#2B7FFF`)이 유지됩니다.

> 반영 시점: 저장 즉시가 아니라 **고객의 다음 위젯 세션**부터입니다.

---

## 4. 알림 채널

어떤 알림을 어떤 경로(이메일·SMS·웹푸시·앱푸시)로 보낼지 상점이 정합니다.
인앱(위젯 알림함)은 항상 켜져 있습니다.

- 여기서 **끈 경로는 고객이 켤 수 없습니다** — 상점 정책이 상한입니다.
- 허용한 경로 안에서 고객은 위젯 설정의 **마케팅 수신 거부**로 프로모션·쿠폰·리뷰 요청을
  거부할 수 있습니다. 주문·배송 알림은 이와 무관하게 발송됩니다.
- 설정하지 않으면 현재 동작이 그대로 유지됩니다.

---

## 5. 자주 묻는 것

**Q. 설정을 바꿨는데 위젯이 그대로입니다.**
고객 브라우저가 이전 세션을 쓰고 있을 수 있습니다. 위젯을 닫았다 열거나 페이지를 새로고침하면
다음 `session/ensure`에서 반영됩니다.

**Q. 탭 설정이 안 보입니다.**
**위젯 탭 구성** 카드입니다. 예전에는 **위젯 동작** 카드 중간에 있었습니다(§1).

**Q. 브랜드 색을 넣었더니 글씨가 검게 나옵니다.**
정상입니다. 밝은 배경에서는 흰 글씨가 읽히지 않아 짙은 회색으로 자동 전환됩니다(§3).
