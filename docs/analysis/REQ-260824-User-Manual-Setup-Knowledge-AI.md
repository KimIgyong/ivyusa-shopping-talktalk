## 1. 요구사항 (원문 요약)

샵톡(ShopTalk) 사용자설명서 작성:

1. **간단 세팅 매뉴얼** — 어드민에서 테넌트 설정 후 추가한 관리자에게 임시비번 발행 → 이를
   전달받은 테넌트 관리자가 로그인 → 사용할 플랫폼 설정(카페24, 쇼피파이, 오두) → 채팅위젯
   설정 → AI 설정 → 지식 입력, 까지의 간단 세팅 흐름.
2. **지식 등록·AI 설정 매뉴얼** — 사용할 지식 입력 방법 및 검증, AI 설정, 실제 라이브챗에서의
   고객 대응 설정 등 운영 단계 사용자 매뉴얼.

### 2.2 제품 현황 (코드 기준 확인 완료, 2026-08-24 현재 브랜치)

콘솔 실제 흐름을 코드에서 전수 확인함. 매뉴얼에 반영할 핵심 사실:

- **테넌트 개설(어드민)**: `/admin/tenants`에서 이름·슬러그·쇼핑몰 도메인·요금제로 생성 →
  행 액션으로 제공 메뉴(플랜 기본/강제 제공/차단) 설정, 사용자 관리로 진입.
- **임시 비밀번호**: 사용자 초대(`/admin/tenants/:uuid/users`) 성공 즉시 모달에 **1회만 평문
  표시**(복사 버튼). **이메일 발송 없음** — 관리자가 안전한 경로로 직접 전달. 재발급 버튼 존재.
  초대 계정은 `must_change_password=1`.
- **첫 로그인**: `/<slug>` 슬러그 로그인 → **닫을 수 없는 강제 비밀번호 변경 모달**(규칙: 10자
  이상·문자종류 3·흔한 비밀번호 금지, 실시간 체크리스트) → 성공 시 토큰 교체. master/director는
  `MFA_ENFORCE_FROM` 이후 MFA(TOTP) 등록 강제(유예 배너 → 차단 모달).
- **플랫폼 연동(/settings)**: Shopify 전용 모달(테스트/동기화/웹훅 등록), 범용 연동 모달
  (cafe24·woocommerce·odoo·haravan·klaviyo·yotpo·gorgias — 스키마 기반 필드),
  **Cafe24 OAuth 연결 카드**(연결→인가→콜백, 주문/상품 동기화 버튼) 별도 존재. 메신저 채널
  (telegram/viber/amoebatalk/btbz_relay/gmail) 카드도 /settings에 있음.
- **위젯 설정(/settings)**: 설치 가이드 카드(플랫폼 4종 탭 + Shopify 3방식), 임베드&SDK(스니펫·
  허용 도메인·서명 시크릿 1회 노출), 위젯 동작/문구(로그인 방식·타임존·표시명·인사말 언어탭),
  위젯 탭(3종, 최소 1개), 위젯 테마(브랜드색·헤더·로고·런처 위치/크기/아이콘 + 미리보기),
  알림 채널 정책, **상담 전환(핸드오프) 섹션도 /settings로 이전됨**.
- **AI 설정(/ai-setting)**: 탭이 아닌 **카드 나열 + 우측 스튜디오(미리보기/AI 코칭)** 구조.
  카드: AI 에이전트(멀티) → 페르소나 → 응답 규칙 → 시나리오 버튼(6개 언어 답변 편집) →
  AI 기능(엔진/온도/토큰) → 모더레이션 규칙 → 회귀 테스트(골든 질문) → 설정 변경 이력 →
  답변 재사용.
- **지식(/knowledge)**: 소스(board/gdrive/notion 지원 — **repository(GitHub)는 UI에 있으나
  "준비 안 됨"**), 자격증명 카드(gdrive 키 JSON, notion 토큰, 연결 테스트), 문서 관리(그룹 탭
  전체/상담/상품, 카테고리 내비게이터, 검토 주기·stale·리비전/복원), **카탈로그 동기화
  (미리보기→실행 2단계)**, 상품 CSV 가져오기, 사용 가이드, 지식 공백 제안함, 답변 제안 승인,
  우측 **지식 QA 패널**(질문→신뢰도→출처→수정→재질문)과 **충돌 검토**.
- **팀원/권한**: `/users` 초대(직급·직무 라벨, 임시비번 모달 동일), `/settings`의 메뉴 접근
  권한(직급별 매트릭스 + 사용자별 예외, master 전용).

## 4. 사용자 플로우 (매뉴얼 1의 골격)

```
[플랫폼 관리자 /admin]                      [테넌트 관리자 /<slug>]
테넌트 생성(이름·슬러그·도메인·요금제)
 → (선택) 제공 메뉴 조정
 → 관리자 초대(master) → 임시비번 1회 표시
 → 로그인 URL + 임시비번 안전 전달  ─────▶  /<slug> 로그인
                                            → 강제 비밀번호 변경 → (MFA 등록)
                                            → /settings 플랫폼 연동(Cafe24·Shopify·Odoo)
                                            → 위젯 설치 스니펫 + 문구·탭·테마
                                            → /ai-setting 페르소나·규칙·엔진 확인
                                            → /knowledge 문서 등록 → QA로 확인
                                            → (선택) /users 팀원 초대 · 상담 전환 설정
```

## 5. 제약·작성 원칙

- **코드 기준 정직 표기** 유지: 기존 매뉴얼의 ✅ 구현됨 / 🟡 준비·로드맵 규칙 승계.
  (예: repository 소스 "준비 안 됨", 예정 메신저 zalo/line/whatsapp)

  (`shoptalk.amoeba.site`) 기준 경로 표기.
- 파일명은 2026-08-04 규칙 `{PREFIX}-{YYMMDD}-{Topic}.md` 적용(GUIDE- 접두). 기존 문서 리네임 금지.
- 임시비번·서명 시크릿 등 **1회 노출 값의 전달 보안** 주의 문구 필수.
- UI 변경 없음 → PLN에 와이어프레임 불필요("no UI impact" 명시).
