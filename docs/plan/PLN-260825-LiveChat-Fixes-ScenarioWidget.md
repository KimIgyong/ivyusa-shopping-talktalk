## 부수영향

- W1은 위젯 공통 경로: 폴백 조건 축소로 "설정 없음(레거시) 테넌트"도 성공-빈배열이면 메뉴가 사라짐 → 서버가 무설정 시 `DEFAULT_SCENARIO_BUTTONS`를 반환하므로 실제 빈배열은 "전부 비활성/전부 타 에이전트 전용"뿐 — 의도된 결과. 에러 시 폴백은 유지(위젯은 항상 메뉴 표시 원칙 중 '표시할 것이 있으면').
- W2로 인라인 셀렉트 제거 — 어제 추가분의 UI 교체(API 불변).
- 유닛: 콘솔 프런트 테스트 인프라 없음 — W1은 위젯도 동일하나 로직이 단순 조건이라 TCR 수동 + 코드리뷰로 커버(기존 관례).
