## R1. 시나리오 에이전트 지정이 챗위젯에 반영되지 않음 (버그)

### AS-IS — 근본 원인 (코드 확인)
- 서버는 정상: `getScenarioForSession`이 세션 에이전트로 필터한 목록을 반환(어제 스테이징 E2E에서 6 vs 5버튼 실증).
- **위젯 `useScenario`의 폴백 조건이 잘못됨**: `if (!buttons || buttons.length === 0) return fallback;` — 스코프 필터로 **버튼이 0개가 되면 하드코딩 6종 폴백을 그대로 표시**한다. 즉 "이 에이전트에는 안 보이게" 지정한 결과가 "전부 보임"으로 뒤집힌다(invisible-fallback-trap의 재발 형태). 부분 필터(1개 이상 남음)만 우연히 동작.
- 부차 요인: `staleTime: 5분` — 운영자가 지정 직후 열려 있던 위젯은 최대 5분간 이전 목록 유지.

### TO-BE
- 폴백은 **fetch 실패/미응답일 때만**. 성공 응답의 빈 목록은 "메뉴 없음"으로 렌더(0개면 ScenarioMenu 미표시).
- `staleTime` 5분→60초(운영자 변경 반영 지연 축소).

## R2. 라이브챗 지정 — 사람 상담원 외에 AI 에이전트 변경도 지원

### AS-IS
- AI 에이전트 변경(PATCH …/ai-agent)은 어제 구현됐으나 **헤더 1줄 좌측의 작은 인라인 셀렉트**라 과밀 속에서 발견성이 낮고, "지정" 흐름([상담원 지정] 버튼/모달)과 분리돼 있어 상담원 지정만 가능한 것으로 인지됨.

### TO-BE
- **지정 모달 통합**: [지정] 버튼 하나 → 모달에서 대상 유형 선택 — (●) AI 에이전트(전 상담원 사용 가능) / ( ) 상담원(manager+에게만 라디오 노출) → 셀렉트 → 지정. AI 지정=기존 재핀 API(다음 응답부터 적용 안내), 상담원 지정=기존 assign API. 인라인 셀렉트는 제거하고 헤더에는 현재 담당 배지(AI: Livy · 상담원명)만 표시.

## R4·R5. 목록 필터 2줄 ("전체/상담필요/종료 필터링 안됨" 포함)

### AS-IS — 진단
- **필터 로직은 정상**: 스테이징 실측 all=50(ai_active40+waiting10) / queue=14 / ended=50으로 서버·클라이언트 파라미터 모두 정확히 동작.
- 실제 문제는 **한 줄 과밀**: [전체|상담필요|종료|그룹] 4탭 + 채널 셀렉트 + 에이전트 셀렉트가 col-span-3 좁은 컬럼 한 줄(`flex`, wrap 없음)에 있어 탭이 압축/오버플로 — 클릭 타깃이 뭉개져 "필터가 안 된다"로 체감되는 UI 결함.

### TO-BE
- **1줄: 전체 / 상담필요 / 종료** (상태 탭만, `shrink-0` 보장)
- **2줄: 그룹 탭 + 채널 셀렉트 + 에이전트 셀렉트**
- [선택](그룹핑 선택 모드) 버튼은 기존 헤더 유지.
