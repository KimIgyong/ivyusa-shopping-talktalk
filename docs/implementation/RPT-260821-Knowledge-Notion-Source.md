## 1. 무엇이 되었나

`/knowledge`에서 노션 데이터베이스나 페이지를 소스로 등록하면 그 내용이 검색되는 지식이 됩니다.
데이터베이스는 **행 하나당 문서 하나**, 페이지는 **자신 + 직계 자식 페이지**. 이후의 업서트·
무변경 건너뜀·미색인 재색인·사라진 문서 숨김·배치 임베딩은 **S1에서 만든 공유 파이프라인이
그대로** 처리합니다. 게시판(S1)·드라이브(S2)에 이어 세 번째 어댑터이고, 파이프라인은 이번에도
거의 손대지 않았습니다.

## 2. 진짜 새로 만든 것은 둘뿐

- **`notion.client.ts`** — 커서 페이지네이션 + **요청 간 350ms 하한**. 동기화 1회는 페이지당 최소
  1요청 + 중첩 블록당 1요청이라 노션의 ~3 req/s 예산에 반드시 닿습니다. 미리 늦추는 편이
  중간에 429를 만나는 것보다 낫습니다.
- **`notion-block-text.util.ts`** — 구글은 문서를 서버측에서 텍스트로 내보내지만 노션은 **블록만**
  돌려줍니다. 노션 페이지가 텍스트가 되는 지점은 여기 한 곳뿐입니다.

나머지는 드라이브 세트의 형태를 **의도적으로 복제**했습니다(같은 자격증명 테이블, 같은 암호화,
같은 `trustEmptyListing=false`). SDK는 추가하지 않았습니다 — `fetch` 두 번이면 되는 일입니다.

## 3. 공유 코드가 두 군데 자랐습니다

| 변경 | 이유 |
|------|------|
| `SourceAdapter.credential` | `createSource`의 `type === 'gdrive'` 하드코딩 제거. 검사 자체는 원래 일반적이었고 하드코딩만 특수했습니다(REQ G5). 드라이브 동작은 불변. |
| `fetchAll → SourceItem[] \| SourceFetch` | 노션은 1회 200페이지 상한이 있고, **잘린 실행이 완전한 실행과 같은 모양으로 보고되면 성공과 구별되지 않습니다.** `dropped`·`truncated`가 결과 JSON → 소스 행 → 토스트까지 도달하고 토스트를 빨갛게 만듭니다. board/gdrive는 배열 그대로. |

## 4. 리뷰에서 잡힌 실제 결함 (PR #331 후속 커밋 2건)

자동 리뷰 18건 중 12건을 반영했습니다. 그중 **내가 만든 진짜 결함**:

1. **한 페이지가 동기화 전체를 세울 수 있었음** — `blocksOf`는 자식 있는 블록마다 1요청인데
   깊이만 제한했습니다. 토글 500개짜리 페이지 = 500요청 ≈ 3분, 200페이지면 수 시간.
   문자 상한은 **다 가져온 뒤에** 적용되므로 방어가 되지 않습니다 → **페이지당 요청 예산** 도입.
2. **타임아웃·`Retry-After` 무제한** — 응답 없는 요청 하나가 동기화를 붙잡고,
   `Retry-After: 86400`은 하루를 대기시킵니다 → 30초 타임아웃, 재시도 대기 30초 상한.
3. **문자 상한에서 잘린 페이지가 어디에도 보고되지 않음** — 로그에만 남았고 콘솔은 로그를
   보여주지 않습니다. 200페이지가 전부 반쪽이어도 완전한 실행처럼 보였습니다.
4. **접두사만 남는 빈 블록** — 빈 헤딩이 `#`으로, 여백용 불릿이 `- `로 색인에 들어갔습니다.
5. **자격증명 변경에 감사기록 없음** — 표준상 특권 작업은 `AuditService.write` 필수.
   노션·드라이브 양쪽 save/remove에 추가(**토큰도 힌트도 기록하지 않음**). 드라이브의 기존 누락도 함께 해소.
6. **복호화 불가 자격증명이 사전검사를 통과** — 키 교체 뒤 남은 행이 소스 생성은 통과하고
   매 동기화마다 실패했을 것.

2차 리뷰에서 **내가 방금 넣은 플래그의 오프바이원 2건**이 더 나왔고, 그걸 쫓다가 밑에 깔린
진짜 결함을 찾았습니다: **문자 상한이 초과 블록을 통째로 버려서**, 첫 문단이 30,000자를 넘는
페이지는 텍스트가 0이 되고 → 빈 페이지로 폐기되고 → **아무 데도 집계되지 않고 사라졌습니다.**
이제 들어가는 만큼은 남깁니다.

**반영하지 않은 3건과 이유**(PR 코멘트에 기록):
- 백엔드 메시지 `session.language` 지역화 — 콘솔 자격증명 경로에는 대화 세션이 없고, 기존 드라이브
  `test()`도 동일하게 영어입니다. 제대로 하려면 결과코드 프로토콜이 필요 → 백로그.
- 목록 ceiling을 `상한+1`로 축소 — 5,000행 DB에서 `dropped: 1`이라고 **거짓 보고**하게 됩니다.
  모호한 수보다 틀린 수가 나쁩니다. 비용은 70초 작업에 3.5초(≈5%).
- 파일명 kebab-case — 이 레포의 리액트 컴포넌트 파일은 전부 PascalCase입니다.
