## 3. S-T9 — 스모크만 잡을 수 있었던 결함

**증상**: 한 카테고리를 다른 에이전트에게 지정하자 **콘솔 운영자 보기에서도 그 카테고리가
사라졌습니다.** 지식을 관리하는 사람이 자기가 방금 좁힌 지식을 못 보게 된 상태.

**원인**: `rag.answer()`가 `aiAgentId=null`을 **기본 에이전트로 해석**했습니다. 두 호출자가
null을 정반대 뜻으로 씁니다 — 콘솔은 "범위 없음", 위젯은 "고정 안 된 세션(=기본 에이전트로
답해야 함)". 안에서 해석하면 둘이 하나로 뭉개집니다.

**수정**(PR #390): RAG는 받은 값을 그대로 적용하고, `chat.service`가 호출 전에 해석합니다 —
바로 윗줄에서 재사용 조회용으로 이미 같은 값을 구하고 있었습니다.

**단위 테스트가 왜 못 잡았나**: 모든 테스트 더블이 `effectiveAgentId → null`을 돌려주고 있어
"해석한다/안 한다"의 차이가 드러나지 않았습니다. 두 호출자가 같은 인자에 다른 의미를 싣는
구조는 **한쪽만 실제로 돌려봐야** 드러납니다.
