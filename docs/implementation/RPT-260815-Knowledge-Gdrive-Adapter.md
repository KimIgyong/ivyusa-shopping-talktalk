## 1. 무엇을 만들었나

테넌트가 드라이브 폴더를 소스로 지정하고 그 폴더를 우리 서비스 계정에 공유하면,
폴더의 **Google Docs·`.txt`·`.md`가 검색되는 지식**이 됩니다.

새로 만든 것은 `fetchAll` 하나뿐입니다. 업서트·무변경 건너뜀·미색인 재색인·사라진 원문
숨김·배치 임베딩·수정 이력은 **S1 파이프라인을 그대로** 씁니다 — S1에서 의도한 구조가
두 번째 어댑터에서 실제로 값을 했습니다.

| 파일 | 역할 |
|---|---|
| `gdrive-credential.util.ts` | 붙여넣은 JSON에서 두 필드 추출·검증 |
| `gdrive-credential.service.ts` | AES-GCM 저장/조회/삭제/연결 테스트 |
| `gdrive.client.ts` | JWT(RS256) → 토큰, 폴더 목록, Docs export |
| `adapters/gdrive.adapter.ts` | Drive 파일 → SourceItem |
| `source-sync.service.ts` | **빈 목록 가드** 추가 |
| 콘솔 | 서비스 계정 카드, 폴더 ID 입력, 연결 테스트 |

## 2. 결정과 근거

| 결정 | 채택 | 근거 |
|---|---|---|
| 인증(D10) | **서비스 계정** | `drive.readonly`는 구글 제한 스코프 → OAuth는 앱 검증 수 주. Shopify 파트너 승인처럼 대기가 생깁니다. 폴더 공유는 검증 불필요 |
| 대상(D11) | **Docs + txt/md** | PDF는 절반이 스캔본(빈 텍스트), 스프레드시트는 CSV 임포터와 중복 |
| 의존성 | **추가 없음** | 레포가 `fetch`를 쓰고 `node:crypto`로 RS256 서명 가능 |
| 스코프 | **읽기 전용** | 실수로도 테넌트 문서를 수정할 수 없게 |

## 3. 이번에 새로 세운 규칙 — 빈 목록 가드

드라이브는 **공유가 끊긴 폴더**에도 **정말 빈 폴더**와 똑같이 "파일 없음"으로 답합니다.
S1 파이프라인은 "원문에 없으면 숨김"이므로, 그대로 두면 **권한 문제 한 번에 그 소스의
지식 전체가 조용히 숨겨집니다.**

이제 외부 소스가 0건을 반환했는데 살아있는 문서가 남아 있으면 **숨김을 거부하고
`last_sync_status='failed'`로 기록**합니다. 게시판은 종전대로입니다 — 빈 게시판은 정말로
글이 없는 것이니까요. 구분은 어댑터의 `trustEmptyListing`이 합니다.

> 이 규칙이 없으면 실패가 "성공했는데 지식이 사라짐"으로 나타납니다. 로그에도 안 남고,
> 답변 품질이 조용히 무너진 뒤에야 발견됩니다.

## 4. 크기 산정 — 추정이 아니라 실측

| | 측정 | 판정 |
|---|---|---|
| 붙여넣는 JSON 전체 | 2,307 B (+AES-GCM 28 B) | **2048 컬럼 초과** |
| 두 필드만 | **1,850 B** (실제 RSA-2048 키) | 수용 |

**두 필드만 저장하는 것**이 실제로 맞춰주는 부분이고, 컬럼 4096 확장은 RSA-4096을 위한
여유입니다. 최소 저장은 크기만큼이나 프라이버시 판단입니다 — 비밀 저장소가 읽지도 않는
값(project_id, cert URL 등)을 갖고 있을 이유가 없습니다.

예전 `external_key VARCHAR(128)`을 평균값으로 잡았다가 실데이터에 거부당한 전례가 있어,
이번엔 **실제 키 형태로 재고 시작**했습니다.

## 5. ⚠️ 검증 상태 — 정직하게

**통과**: 단위 37건(전체 1233) · 실 DB 시나리오 8건 · 마이그레이션 멱등 · 부팅 · 스테이징 배포(401)

**미검증**: **실제 드라이브 왕복 전체.** 서비스 계정이 없어 토큰 발급·폴더 목록·Docs
export는 **HTTP 목으로만** 확인했습니다. 실제 구글 오류 응답 형태, 200개 초과 폴더의
페이지네이션, 권한 회수 시 가드 실동작은 아직 확인되지 않았습니다.

활성화에 필요한 것(계정 소유자 작업):

1. GCP 프로젝트 생성 + **Drive API 활성화**
2. 서비스 계정 + JSON 키 발급
3. 대상 폴더를 서비스 계정 이메일에 **뷰어로 공유**
4. 콘솔 `/knowledge`에서 키 붙여넣기 → `[연결 테스트]`

키 등록은 운영자가 직접 합니다. 자격증명 입력을 대행하지 않았습니다.

## 8. 운영 안내 필요

- 드라이브 소스는 **폴더 최상위 파일만** 가져옵니다. 하위 폴더는 별도 소스로 등록해야 합니다.
- 폴더 공유를 해제하면 문서가 사라지지 않고 **동기화가 실패로 표시**됩니다(가드). 콘솔의
  마지막 동기화가 빨간색이면 공유 상태를 먼저 확인하십시오.
- PDF·스프레드시트는 **의도적으로 제외**됩니다. 상품표는 기존 CSV 임포터를 씁니다.
