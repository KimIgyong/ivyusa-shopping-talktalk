## 3. 타입 변경이 잡아낸 소비처

`label: string` → `string | LocalizedText`로 넓히자 컴파일러가 **3곳**을 즉시 멈춰 세웠고, 리뷰가
**4번째**를 찾았다(문자열 보간 자리라 타입이 못 잡는다).

| 소비처 | 조치 |
|---|---|
| 콘솔 버튼 목록 입력칸 | 언어 탭 + 언어별 편집 |
| 에이전트 적용 설정 뱃지 | `scenarioLabelText`로 해석 |
| **미리보기 패널 칩** | 패널 자체 언어 선택기 값으로 해석 |
| **에이전트 범위 모달 힌트**(리뷰 검출, PR #466) | 해석 후 보간 — 그대로 두면 `[object Object]` |

## 5. 실측 — 기본값 다국어화가 닿는 범위

스테이징 14개 테넌트 중 `scenario_buttons`를 저장한 곳은 **4곳뿐이고, 4곳 모두 평문(영어) 라벨**이다.
나머지 10곳은 저장분이 없어 이번 **다국어 기본값**을 그대로 받는다.

저장분이 있는 4곳(ivyusa·go2joy 포함)은 예전에 설정 화면에서 한 번 저장하면서 그때의 영어 기본값이
행에 굳은 경우다. 이제 콘솔에서 언어별로 고칠 수 있고, 버튼을 전부 지우면 다국어 기본값으로 되돌아간다.
자동 마이그레이션은 하지 않았다 — 저장된 라벨이 기본값 그대로인지 테넌트가 손댄 것인지 서버가 알 수 없다.
