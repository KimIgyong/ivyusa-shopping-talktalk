# 운영 공지 — 개인정보보호 개편에 따른 행동 변경 (2026-07-31 배포)

| 항목 | 내용 |
|---|---|
| 문서 ID | OPS-NOTICE-Privacy-20260731 |
| 대상 | 테넌트 운영자(마스터/디렉터), 상담원, 시스템 관리자 |
| 적용 시점 | 2026-07-31 staging 배포부터 (PR #39~#44, main `47b00d4`) |
| 근거 | RPT-Privacy-Control-Gap-20260731 §4 |

## 1. 미동의 고객 채팅 차단 (가장 중요)

**변경 전**: 동의 배너에서 아무것도 선택하지 않은(PENDING) 고객도 채팅·AI 답변 이용 가능.
**변경 후**: **동의(GRANTED) 전에는 채팅이 처리되지 않습니다.** 메시지는 저장·AI 전송 없이
"개인정보 고지 수락 후 이용 가능" 안내로만 응답합니다. 거부(DECLINED)·구버전 동의도 동일합니다.

- 상담원 참고: 미동의 세션에는 상담원 답장도 차단됩니다(403). 고객이 동의를 완료해야 대화가 재개됩니다.
- 예상 영향: 동의 전 이탈이 소폭 늘 수 있으나, 배너가 저장 실패 시 재시도를 지원하도록 개선되어
  "선택했는데 반영 안 됨" 문제는 사라졌습니다.

## 2. 개인정보 고지 버전 변경 시 전 고객 재동의

콘솔 **설정 > 개인정보 고지**(마스터/디렉터 전용)에서 처리방침 URL과 고지 버전을 관리합니다.

- **버전을 변경하면 기존 동의가 모두 무효화**되어 전 고객에게 동의 배너가 다시 표시됩니다.
  방침의 실질 변경(수집 항목·목적·제3자 변경) 시에만 버전을 올리세요. 오탈자 수정은 URL 문서만 고치면 됩니다.
- 버전 미설정 시 플랫폼 기본값(`2026-07`)이 적용됩니다.
- 처리방침 URL을 등록하면 위젯 동의 배너에 "전문 보기" 링크가 노출됩니다. 등록을 권장합니다.

## 3. 마케팅성 알림은 명시적 수신 동의 필요 (opt-in)

**변경 전**: 수신 설정이 없는 고객에게도 이벤트/리뷰 알림 외부 발송 허용(default-allow).
**변경 후**: **이벤트·리뷰(마케팅성) 알림은 고객이 수신 설정을 켠 경우에만 외부 발송**됩니다.
결제·배송(거래성) 알림과 인앱 알림은 기존대로 발송됩니다. 비식별 고객에게는 외부 발송이 되지 않습니다.

- 캠페인 외부 전달도 동일 규칙을 따릅니다(현재 외부 발송 채널은 mock이라 실영향 없음 —
  실제 이메일/SMS 제공자 도입 시 이 규칙이 그대로 적용됩니다).

## 4. 비밀번호 정책 강화 (다음 변경부터)

- 신규/변경 비밀번호: **12자 이상 + 문자 종류 3가지 이상**(대/소문자·숫자·특수문자), 흔한 비밀번호 차단,
  이메일·이름 파생 문자열 금지, 직전 비밀번호 재사용 금지.
- 기존 비밀번호로 로그인은 계속 가능합니다(강제 리셋 없음). 다음 변경 시부터 새 정책이 적용됩니다.
- 관리자 발급 임시 비밀번호는 자동으로 새 정책을 충족합니다.

## 5. 2단계 인증(MFA) 도입 — 2026-08-14부터 필수 (2026-07-31 추가)

- **대상**: 시스템 관리자 전체, 테넌트 master/director. (manager/staff는 선택 — 등록 시 동일 적용)
- **지금부터 가능**: 마이페이지 > 2단계 인증에서 인증 앱(QR 또는 수동 키) 등록. 등록 시 표시되는 **복구 코드 10개는 1회만 표시**되므로 반드시 저장하세요.
- **2026-08-14부터**: 미등록 필수 대상은 로그인 후 등록 화면 외 콘솔 사용이 제한됩니다. 그 전까지는 상단 배너로 안내됩니다.
- **분실 시**: 복구 코드로 로그인 → 재등록. 복구 코드까지 분실하면 관리자가 사용자 관리에서 "MFA 리셋"(감사 기록됨) → 다음 로그인에서 재등록.
