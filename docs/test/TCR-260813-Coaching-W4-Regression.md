## 1. 단위 테스트 (신규 8건, 전부 통과)

이 기능의 가치는 두 가지가 맞아야 성립한다 — **질문이 실제로 전부 물어졌는가**, 그리고
**비교가 근거 없는 결론을 내지 않는가**.

| # | 케이스 | 기대 | 결과 |
|---|---|---|---|
| G-01 | 빈 세트로 실행 | **E4017 거부** — 빈 통과는 통과가 아니다 | ✅ |
| G-02 | 활성 질문 전부 질의·기록 | 순서대로 2건 질의, 항목 2건 저장 | ✅ |
| G-03 | 중간 질문 실패 | 런 전체를 잃지 않고 **error로 기록 후 계속** | ✅ |
| G-04 | 상한 초과 세트 | 20건만 실행 + **`truncated` 표시** (조용한 절단 금지) | ✅ |
| G-05 | config 해시 | 같은 설정=같은 해시, 규칙 추가=다른 해시 | ✅ |
| G-06 | 비교 신호 | 신뢰도Δ·인용변경·문구변경 보고, **판정 문구 없음** | ✅ |
| G-07 | 같은 해시 두 런 비교 | **`sameConfig=true`** — 차이는 효과가 아니라 변동 | ✅ |
| G-08 | 세트가 바뀐 뒤 비교 | 질문을 **텍스트로 매칭**, 없는 쪽은 null | ✅ |

**G-04가 중요한 이유**: 일부만 실행하고 완료처럼 보이는 런은 없는 것보다 나쁘다 — 대부분 묻지도
않고 "다 통과"로 읽힌다.

**G-07이 이 PR의 핵심 주장**이다. 같은 설정으로 두 번 돌린 비교는 "모델이 스스로 얼마나 움직이는가"를
재는 것이지 변경의 효과가 아니다. 이 구분이 없으면 모든 diff가 회귀로 보인다(W3 실측 O-1).

## 3. 스테이징 실 LLM 검증 (2026-08-13 배포 후) — **S-02 / S-04 완료**

tenant 1, 골든 질문 3문항(배송기간·반품배송비·쿠폰사용). 검증 전후 persona·rules(10건) 동일 확인.

### S-02 — 노이즈 기준선 (이 PR에서 가장 중요한 산출물)

설정을 **전혀 바꾸지 않고** 같은 세트를 2회 실행해 비교했다(`sameConfig=true`).

| 문항 | 신뢰도Δ | 길이Δ | 인용변경 | 문구변경 |
|---|---|---|---|---|
| 배송은 보통 얼마나 걸리나요? | **0** | +3 | 예 | **예** |
| 반품 배송비는 누가 부담하나요? | **0** | +3 | 아니오 | **예** |
| 쿠폰은 어떻게 사용하나요? | **0** | +6 | 아니오 | **예** |

**결론 — 신호별 신뢰도가 실측으로 정해졌다.**

| 신호 | 노이즈에서의 거동 | 판단 가치 |
|---|---|---|
| **문구 변경** | **3/3 항상 바뀜** | ❌ **신호 아님.** 설정을 안 바꿔도 100% 바뀐다 |
| 길이 | ±3~6자 흔들림 | ⚠️ 작은 변화는 무의미 |
| 인용 변경 | 1/3에서 발생 | ⚠️ 약한 신호 |
| **신뢰도** | **3/3 전부 Δ=0** | ✅ **강한 신호.** 움직이면 실제로 무언가 달라진 것 |

**이 표가 W3 관측 O-1을 설명한다.** 그때 "문구는 바뀌었는데 의도는 안 보인다"고 했던 것은
**정상적인 노이즈**였다. 문구 변경을 근거로 판단하려 한 것 자체가 잘못이었고, 그래서 이 기능이
문구 변경을 "회귀"라고 부르지 않는 설계가 옳았음이 실측으로 확인됐다.

### S-04 — W3의 O-1을 여러 문항으로 다시 판단

W3와 같은 취지의 규칙("배송·배송기간 질문은 기다림에 대한 공감 한 문장으로 시작")을
**`apply-verified`로 적용**(baseline → 적용 → after, `sameConfig=false`).

| 문항 | 적용 후 첫 문장 | 판정 |
|---|---|---|
| 배송은 보통 얼마나 걸리나요? | **"기다리시는 마음 충분히 이해합니다."** | ✅ 규칙이 적용됨 |
| 반품 배송비는 누가 부담하나요? | "안녕하세요! 반품 배송비에 대해…" | ✅ 대상 아님 — 그대로 |
| 쿠폰은 어떻게 사용하나요? | "안녕하세요! 쿠폰 사용 방법…" | ✅ 대상 아님 — 그대로 |

**대상 문항만 바뀌고 나머지는 그대로**라는 것이 한눈에 보인다. W3에서는 답변 하나만 보고
"안 먹힌 것 같다"고 판단할 수밖에 없었다. 이제는 판단할 수 있다 — **이것이 W4가 존재하는 이유이고,
그 목적이 달성됐다.**
