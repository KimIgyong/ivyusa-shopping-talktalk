## 4. 알려진 한계

- 콘솔 미리보기는 **목업**이다. 실제 위젯을 iframe으로 띄우면 테마를 만질 때마다 게스트 세션이
  생기므로 의도적으로 선택하지 않았다(PLN §4.1). 색은 위젯과 **같은 함수**로 계산하므로
  어긋나지 않지만, 레이아웃은 근사다.
- 런처가 왼쪽일 때 스토어 자체 UI(장바구니 버튼 등)와 겹칠 수 있다 — 여백 조정은 FR-T3 범위.
- 로고가 있는데 파일이 사라진 경우(볼륨 초기화) 위젯은 텍스트로 폴백하지만, 콘솔은 깨진
  이미지를 보여줄 수 있다.
