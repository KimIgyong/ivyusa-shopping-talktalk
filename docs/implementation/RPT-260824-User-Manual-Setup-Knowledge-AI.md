## 2. 사실 검증 (TCR 갈음 — docs-only)

콘솔·위젯·API 코드를 조사(2회 전수 탐색 + 스팟체크)해 매뉴얼의 모든 절차·필드명을 코드와
대조했다. 매뉴얼에 반영된 주요 확정 사실:

| 검증 항목 | 결과 (코드 근거) |
|---|---|
| 임시 비밀번호 | 이메일 발송 없음, 모달 1회 표시·재발급만 가능, 형식 `Ivy`+9자+`!` (`user.service.ts`, `password-policy.util.ts:156`) |
| 비밀번호 정책 | 최소 10자·문자종류 3종·블록리스트 (`password-policy.util.ts`) |
| **temperature** | **Anthropic 어댑터는 의도적으로 전송하지 않음**(모델이 400 거부) — 콘솔 입력은 Anthropic 엔진에 무효, max_tokens만 유효 (`anthropic.adapter.ts`) → D2 §4.4·FAQ, D3 FAQ에 명시 |
| **"차단 키워드"** | 실제 명칭 "정책 강제 핸드오프(deny-list)" — 메시지 차단이 아니라 **AI 생략 + 즉시 인계 + 이슈 유형/라벨 스탬프** (`handoff-router.service.ts`, `chat.service.ts:619`) → D2 §5 반영 |
| 지식 소스 | board/gdrive/notion 지원, repository는 UI에 있으나 미지원("준비 안 됨") — S3 GitHub 연동은 8/24 제외 결정으로 매뉴얼에 "미지원"으로만 표기 |
| 방치 자동 마무리 | 30분 무응답 프롬프트 → 60초 후 종료, 7일 초과 정리, 위젯 채널 한정 (`idle-conversation.service.ts` 기본값) |
| CSAT | 위젯 전용, 종료 후 24h 창(서버 관장), 이모지 5단계=1~5점 |
| 위젯 마케팅 수신 | 카테고리×채널 매트릭스는 위젯에서 제거 — 단일 "마케팅 수신 거부" 토글 + 콘솔 정책 상한 |
