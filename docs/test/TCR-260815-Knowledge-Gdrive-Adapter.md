## 5. ⚠️ 검증하지 못한 것

| 항목 | 사유 |
|---|---|
| **실드라이브 왕복 전체** | 서비스 계정이 존재하지 않습니다. 토큰 발급·폴더 목록·Docs export는 **HTTP 목으로만** 검증됐습니다 |
| 실제 구글 오류 응답 형태 | 401/403 처리 경로는 목 기준. 실제 문구는 다를 수 있습니다 |
| 대용량 폴더 | 페이지네이션은 목으로 검증. 실제 200개 초과 폴더 미확인 |
| 권한 회수 시 가드 | 가드 로직은 단위 검증(G1). **실제 공유 해제 재현은 미실시** |
| 하위 폴더 | 현재 **최상위 폴더만** 조회합니다(재귀 없음) — 설계대로이나 운영 안내 필요 |

G4(실연동)는 아래 3가지가 준비되면 진행합니다.

1. GCP 프로젝트 + **Drive API 활성화**
2. 서비스 계정 JSON 키
3. 대상 폴더를 서비스 계정 이메일에 **뷰어 공유**
