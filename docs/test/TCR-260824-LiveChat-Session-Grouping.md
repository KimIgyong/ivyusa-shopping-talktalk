## 4. 엣지 케이스 (설계로 처리)

- 같은 세션의 행을 여러 개 체크: sessionId 기준 Map이라 멤버 1명으로 접힘.
- 같은 세션을 같은 그룹에 재추가: DB 유니크 + 서비스 중복 스킵(에러 아님).
- 멤버 세션에 대화가 0건: 발신 시 대상 대화방 없음 → E5058(이론상 목록에 노출되지 않는 세션이라 실경로 없음).
- 그룹 제목 100자 초과: DTO MaxLength + 서버 slice 이중 방어.
- 유형 변경(타임라인↔프로젝트): 라벨만 바뀌고 어떤 동작도 변하지 않음(구분자 원칙).
