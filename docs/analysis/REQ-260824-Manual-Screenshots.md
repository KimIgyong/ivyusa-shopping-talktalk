## 1. 요구사항 (원문)

HTML 버전 매뉴얼에 주요 메뉴 화면 스크린캡처 화면을 추가한다.

## 2. AS-IS

- `/manual`의 HTML 매뉴얼 9종(3문서 × ko/en/vi)은 **텍스트·표·ASCII 개요도만**으로 구성.
  실제 화면 모습이 없어 처음 보는 운영자가 화면을 머릿속으로 그려야 함.
- md 버전은 원문 열람용 — 이번 요구 범위는 **html 버전만**.

## 3. 캡처 소스 제약 (사전 조사 완료)

| 후보 | 판정 |
|---|---|
| 스테이징 콘솔 실화면 | ⚠️ 부적합 — ① master/director MFA 강제(8/14~)로 자동 로그인 불가 ② 실데이터(고객명·이메일·주문·대화)가 찍혀 **공개 매뉴얼에 PII 노출** 위험 |
| **로컬 dev + 시드 데모 데이터** | ✅ **권장** — `MFA_ENFORCE_FROM` 미설정(주석)이라 로그인 차단 없음, 시드 데이터는 데모용이라 PII 무해, 재현 가능(누구나 같은 절차로 재캡처) |

로컬 dev 화면은 스테이징과 동일한 코드/UI이므로 매뉴얼 목적에 충분하다.
(로컬 URL 표시줄은 캡처에서 제외하거나 크롭.)

## 4. TO-BE

- 주요 메뉴 화면 캡처(뷰포트 통일, 다듬은 상태)를 `apps/web/public/manual/img/`에 저장하고
  각 HTML 매뉴얼의 해당 절에 **figure(캡처 + 캡션)** 로 삽입.
- md 버전은 변경하지 않음(원문 유지). 배포 후 `/manual/img/...`로 서비스.

## 5. 제약·원칙

- 캡처에 개인정보·실키·시크릿이 보이지 않을 것(시드 데모 데이터만).
- 파일 용량 관리: JPEG/WebP, 폭 ~1600px, 장당 수백 KB 이내.
- 언어: 콘솔 UI 언어를 바꿔 캡처하면 세트가 3배가 됨 → PLN 오픈 이슈로 결정.
- 이미지에 `loading="lazy"` + `alt`(현지어) 필수, 다크/라이트 테마와 무관하게 라이트
  테마 콘솔로 통일 캡처.
