## 예방 패턴

**"곧 제공됩니다" 류의 예고 문구는 만들 때 회수 조건을 함께 적는다.** 예고 문구를 넣는
PR 본문에 "X 출시 시 이 키(`boardBannerBody`) 갱신"을 남기고, 출시 PR 쪽 체크리스트에서
지운다. 예고 문구는 기능 플래그와 같아서, 켜는 쪽(출시)만 있고 끄는 쪽(회수)이 없으면
반드시 낡는다. — 매뉴얼류 문서가 같은 이유로 낡는 것의 초소형 버전.

같은 PR에 포함된 문서 정리(비버그): 사용자매뉴얼_User-Manual.html(v1 유물) 퇴역,
platform-integration en/vi의 figcaption "도식" 칩 언어화, 위젯설정가이드 현행화(7탭·
로고/런처·6언어 인사말), AI-SETTINGS-GUIDE v2.0(심화 문서로 재정의 — 절차는 지식·AI
매뉴얼로 일원화).
