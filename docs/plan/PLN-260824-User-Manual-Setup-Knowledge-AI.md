## 2. D1 — 간단 세팅 매뉴얼 목차(안)

```
0. 개요 — 대상 독자(어드민/테넌트 관리자), 소요 시간, 준비물, 콘솔 URL 규칙(/<slug>)
1. [플랫폼 관리자] 테넌트 개설           (/admin/tenants)
   1.1 새 테넌트 생성 — 이름·로그인 경로(slug 규칙·예약어)·쇼핑몰 도메인·요금제
   1.2 (선택) 제공 메뉴 조정 — 플랜 따름/강제 제공/차단
   1.3 테넌트 관리자 초대(master) → 임시 비밀번호 발급
       ⚠️ 메일 발송 없음 · 1회만 표시 · 재발급 방법 · 안전한 전달 경로
   1.4 로그인 URL(origin+/slug) 복사·전달
2. [테넌트 관리자] 첫 로그인
   2.1 /<slug> 접속·로그인 (이메일 기억하기, 실패 시 힌트)
   2.2 강제 비밀번호 변경 — 규칙 3종 체크리스트
   2.3 MFA 등록 — master/director 강제 정책, QR·복구 코드 10개 1회 표시
3. 커머스 플랫폼 연동                    (/settings 스토어 연동)
   3.1 Cafe24 — OAuth 연결 카드(권장) / 수동 자격증명, 주문·상품 동기화
   3.2 Shopify — 자격증명, 연결 테스트·동기화·웹훅 등록 (상세는 연동 가이드 링크)
   3.3 Odoo — url/db/username/api_key, 연결 테스트
   3.4 스토어프론트 URL 설정 (미설정 시 상품 링크 비활성)
4. 채팅위젯 설정                         (/settings 위젯 카드들)
   4.1 위젯 설치 — 설치 가이드 카드(플랫폼별 스니펫) + 임베드&SDK(허용 도메인·서명 시크릿)
   4.2 문구·동작 — 표시 이름·인사말(언어 탭)·로그인 방식·타임존
   4.3 탭·테마 — 탭 3종(최소 1개), 브랜드 색·헤더·로고·런처 (상세는 위젯설정가이드 링크)
5. AI 최소 설정                          (/ai-setting)
   5.1 페르소나·응답 규칙 작성
   5.2 AI 기능 엔진 확인 — stub 경고의 의미, 엔진은 어드민이 등록
   5.3 시나리오 버튼 점검 (기본 6종)
6. 지식 최초 입력                        (/knowledge)
   6.1 핵심 정책 문서 3~5건 수동 등록 (배송·취소환불·FAQ)
   6.2 지식 QA 패널로 답변 확인
7. (선택) 팀원 초대(/users) · 상담 전환 설정(/settings) 미리보기 — D2로 안내
8. 완료 체크리스트 — 위젯 실동작 확인 절차 포함
9. 문제 해결 — 로그인 안 됨/임시비번 분실/위젯 안 뜸/AI가 stub 응답
```

## 3. D2 — 지식 등록·AI 설정 매뉴얼 목차(안)

```
0. 개요 — 지식→AI→라이브챗의 관계(응답 파이프라인 한 장 그림)
1. 지식 구조 이해 — 문서/소스/그룹(상담·상품)/카테고리, RAG 검색·신뢰도·에스컬레이션
2. 지식 등록
   2.1 수동 문서 — 추가·편집·카테고리·적용 시작일·검토 주기·재임베딩
   2.2 상품 지식 — 카탈로그 동기화(미리보기→실행 2단계, 병합·보류 읽는 법),
       상품 CSV 가져오기, 유형별 사용 가이드 작성
   2.3 외부 소스 — board / Google Drive(서비스계정 키·폴더 공유) / Notion(토큰·통합 연결),
       연결 테스트, 동기화 결과 읽는 법(dropped/truncated 경고) · 🟡 repository는 준비 안 됨
3. 지식 검증·품질 관리
   3.1 지식 QA 패널 — 질문→신뢰도→출처→[수정]→재질문 루프
   3.2 충돌 검토 — 재스캔, A/B/둘 다 유지·무시·재판정
   3.3 검토 주기·stale 배지·검토 완료 처리, 변경이력·복원
   3.4 지식 공백 제안함·답변 제안 승인 (라이브챗발 폐루프)
4. AI 설정
   4.1 AI 에이전트(멀티 페르소나) — 추가·기본 지정·진입점 스니펫
   4.2 페르소나·응답 규칙 — 작성 요령·변경 메모·설정 변경 이력
   4.3 시나리오 버튼 — 액션 7종, 답변 편집(6개 언어·후속 버튼)
   4.4 AI 기능 — 기능 5종 용도, 엔진 선택·temperature·max_tokens·폴백 사슬
   4.5 모더레이션 규칙 — 유형(word/phrase/regex/context)·범위·조치, fail-safe 차단
   4.6 답변 재사용 — 검색·편집·전체 비활성화
5. 라이브챗 고객 대응 설정                (/settings 상담 전환)
   5.1 담당자 지정·영업시간·휴게시간·영업외 이메일·안내 문구(언어 탭)
   5.2 SLA 목표·차단 키워드 규칙
   5.3 에스컬레이션 조건 이해 — 신뢰도·모더레이션 차단·고객 요청
6. 검증·개선 루프                        (/ai-setting 우측 스튜디오)
   6.1 미리보기 — 고객/상담원 모드, 언어별 테스트
   6.2 AI 코칭 — 스레드·참조 턴·제안 적용/거절/되돌리기
   6.3 회귀 테스트 — 골든 질문·변동성 측정·이전과 비교
7. 운영 체크리스트 — 정책 변경 시 절차(스크립트 답변·KB 동시 갱신 포함)
8. FAQ / 문제 해결
```
